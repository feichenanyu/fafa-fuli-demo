# 88buys C端兑换商城 · 五种风格原型

在线浏览：https://feichenanyu.github.io/fafa-fuli-demo/mall-styles/

五种风格：淘宝、Shopify、拼多多、京东、天猫超市。每种风格 6 个页面：

| 页面 | 文件 |
| --- | --- |
| 首页（推荐 / 超市可切换，入口区左右滑动，品牌头条自动滚动） | `pages/{风格}-home.html` |
| 渠道频道页（天猫超市示例，电商精选 / 天猫优品 / 品牌优选共用模板） | `pages/{风格}-channel.html` |
| 数字权益 | `pages/{风格}-cards.html` |
| 本地生活 · 到店餐饮 | `pages/{风格}-life.html` |
| 生日礼遇 | `pages/{风格}-bday.html` |
| 影音娱乐 | `pages/{风格}-movie.html` |

风格前缀：`tb` 淘宝、`sp` Shopify、`pdd` 拼多多、`jd` 京东、`cs` 天猫超市。

## 设计约定

- 资源范围：实物（天猫超市、电商精选、天猫优品、品牌优选）、虚拟卡券、H5 服务（淘宝闪购、美团外卖、小象超市、大润发、电影订座、蛋糕、高德打车）、到店点餐（麦当劳、星巴克、肯德基、奈雪的茶、库迪咖啡）。企业码暂不进商城（微信终端不兼容）。
- 虚拟卡券都是独立 SKU：兑换后发放卡密 / 激活码 / 券码，在「我的卡券」查看，不做直充；不支持加入购物车。
- 商城额度是现金抵用金（1 元 = 1 元），不是积分。价格写法：¥售价 + 金色「抵」标（可用抵用金支付）+ 划线零售价。
- 天猫超市品牌色为绿色（2019 年品牌升级后统一）。
- 渠道入口目前是文字色块占位，上线时替换为已授权的官方 Logo。
- 商品、价格、销量均为示例数据。

## 修改记录

### 2026-11-24 · v3

- 五套风格统一以淘宝首页内容为基础：推荐 / 超市可切换、入口区两页左右滑动（第 2 页为卡券直达）、限时秒杀通栏、礼包专区、到店餐饮、品牌头条、猜你喜欢；去掉积分卡片和商品流筛选标签。各风格保留一个特色模块：Shopify 品牌标语与页脚、拼多多「爆款热销」、京东「福利会员」、天猫超市服务保障条与「囤货清单」。
- 「积分」全部改为「抵用金」（现金抵用额度，1 元 = 1 元），价格标由「积」改为「抵」。
- 到店餐饮只保留 5 个合作品牌（麦当劳、星巴克、肯德基、奈雪的茶、库迪咖啡），首页一行平铺，本地生活页改为点餐列表。
- 品牌头条改为单行慢速自动滚动（约 48 秒一圈），按住暂停；系统开启「减弱动态效果」时改为手动横滑。
- 视觉精修：卡片柔和阴影与半透明描边、半透明文字色阶、正文 14px / 辅助 12px / 最小 11px；标题按风格与板块区分样式。
- 实测（淘宝首页，390px）：对比度不达标 25 处 → 0，过小点击目标 6 个 → 0。
- 替换 6 张与商品不符的家电图，改用品牌横幅中裁出的真实商品（小熊、华为、无印良品、全棉时代、京觅），商品名与示例价相应调整。
- 产品手动修改已保留：拼多多搜索框拉宽、京东风格标题位置。

## 源文件

`source/` 是 Claude 设计画布的原始文件（`.dc.html` 每个文件一个页面，`canvas.json` 是画布布局），和画布上的版本逐字节一致。`pages/` 由源文件转换而来：图片换成 `assets/` 里的本地文件，页面之间的跳转改成普通链接，底部导航吸底。
