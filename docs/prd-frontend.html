二、产品概述

发发福利首期在 2026-11-20 上线「从进入到结算开票」的最小闭环，支撑 2027 春节福利成交。

2.1 定位

  • 采发发是政企 AI 采购平台，以中小企业和采购服务商为主；发发福利是其中的福利采购应用。
  • 一个页面解决两类需求：有节日或关怀场景的福利采购（福利场景）和不带场景的日常采购（商品资源）；疑问、定制和经营分析走专家咨询。
  • 爆品、礼包、卡券共用一个商品库、一套交易中台和会员底座，由运营按频道组织，不再作为一级导航。
  • GUI 与对话并存：对话理解需求、选品和答疑，加购之后的下单、支付、履约、售后、开票在 GUI 完成。
  • 主要用户是采购服务商：用户说的预算默认是甲方客户预算，选品要留出服务商的利润空间（3.4）。

2.2 首期目标

目标 衡量方式
支撑春节档成交 春节档 GMV（11-20 至 2027 春节档结束，已支付 − 退款），目标值由业务上线前给出
一页式采购跑通 下单漏斗各步转化率、AI 推荐采纳率、场景推荐点击率
个人用户转企业 个人升级企业版率
合规红线零违规 个人账户生成订单数 = 0；个人账户会员价泄露 = 0

2.3 本期范围

  • 采购商前台：侧栏入口、发发福利一页（第六章）、AI 对话与任务栏（第七章）、交易与账户（第八章）。
  • 供应商端：礼包组包；子单发货、售后审核、开票（第九章）。
  • 运营管理后台：商品与资源、频道运营（广告位、场景频道、资源频道、场景推荐）、交易、财务、会员、福利知识库、Agent 运营、数据看板、系统设置（第十章）。
  • 底座：商品数据标准化、福利知识库、CUI 底座接口（不对外开放）。

2.4 本期不做

C 端消费商城与移动端 H5；企业对账单与自动对账；个人账户下单；多级审批；卡券制卡；储值类卡券；礼包部分售后与批量售后；合并开票；接口对外部 AI 开放；平台自行组包；商品铺货到商城；用户主动申请预付款退款；资源广场中的 H5 / 页面类资源。

3.4 预算口径与利润差价

服务商按会员价向平台采购、按分销价与甲方结算，中间差价是其利润；因此用户说的预算默认按**客户预算（对客价口径）**理解，选品前先扣出利润。毛利率以对客价为分母，与分采通口径一致。

概念 定义
目标毛利率 m 用户本轮说的 > 账户「业务偏好」默认值 > 平台默认（建议 15%，待业务确认）
可用采购预算（人均） 客户预算 × (1 − m) − 人均另收运费
建议对客价 采购成本 ÷ (1 − m)，向上取整到元，不超过客户预算
预计利润 (建议对客价 − 采购成本) × 人数
卡券 面值即对客价，利润 = 面值 − 会员价，不再额外扣 m

口径判定：提到客户、甲方、单位、报价 → 对客（默认）；「我们自己员工」→ 自用，m = 0；「采购价 / 成本控制在 X」→ 成本口径，不扣利润。判断不了时按账户默认，在方案卡上标出假设并可切换。个人账户不计算、不展示任何成本与利润。

四、信息架构

首期涉及 4 个端：采发发侧栏「发发福利」是入口；发发福利一页承接找货与对话；交易与账户用独立页；运营后台配置一页的全部内容；供应商端提供礼包货源并处理发货、售后、开票。

4.1 发发福利一页（自上而下）

  1. 吸顶页头：标题「发发福利」、采购车（带件数）；中间常驻商品搜索框；下滑后 AI 对话框收为底部小对话框。
  2. 广告位：弧形卡片轮播，运营配置。
  3. 标题「发发福利 · 政企采购专家」与一句说明。
  4. 固定栏目：福利场景 / 商品资源 / 专家咨询（纯文字分段开关）。
  5. 运营频道（福利场景、商品资源下出现）：场景频道或资源频道 + 「更多」下拉。
  6. AI 对话框：自由输入、场景上下文标签、发送。
  7. 底部联动 GUI：场景运营页 / 资源频道商品 / 场景推荐（随栏目与频道切换）。

发送需求后进入任务对话页（左对话、右任务栏）；购物车、结算、订单、账户为独立页，返回时回到发发福利一页并保留栏目、频道和已输入内容。

五、核心业务流程

七条流程覆盖首期闭环；对话只承担找货与答疑，从加购结算起全部在 GUI 独立页完成。

5.1 找货下单（主流程）

  1. 侧栏点「发发福利」进入一页，默认栏目「福利场景」、频道为当季首推（当前新春年货节），底部展示该场景运营页。
  2. 找货三选一：① 在对话框输入需求（如「客户预算人均 300，给甲方 200 人发年货」）；② 在底部场景运营页或资源频道浏览；③ 点场景推荐里的提问建议。
  3. 走①时进入任务对话页：AI 先识别意图，再用 2–6 轮反问（目标群体 → 合规确认 → 人数与预算 → 按候选池自动挑选的维度）逐步缩小范围，右侧需求画像显示条件、合规说明与当前范围档位（较宽 / 适中 / 已聚焦），过程中不展示精确数量；停止后执行「召回 → 选品 → 自检 → 修正」循环，在右侧给出全部满足条件的 SKU（含采购成本、建议对客价与利润），可筛选、多选后加购。
  4. 加购：方案内勾选商品加购（每件数量 = 人数）或单品加购；「立即购买」只结算本次商品。
  5. 进入确认订单页：选收货方式（单地址 / 名单代发）、看拆单预览；个人账户在此进入 5.2。
  6. 提交生成 1 个主单，系统按来源拆为子单（主单号-1 / -2…），进入收银台：合并支付或按子单分别支付；超阈值先审批。
  7. 支付后子单推送对应供应链或供应商发货；电子卡从卡池分配卡密。
  8. 子单发货 → 签收 → 已完成 → 进入「未结算」，可多选申请开票。

5.2 个人账户升级

  1. 个人账户点任何下单入口 → 升级引导，不生成订单。
  2. 上传营业执照提交 → 审核中（仍是个人账户，只保留购物车）。
  3. 运营 3 个工作日内审核 → 站内信 + 短信通知。
  4. 通过：转为企业账户，购物车按会员价重算，一键回到结算；驳回：展示原因，可重新提交。

5.3 名单代发

  1. 确认订单页选「上传名单代发」→ 下载模板 → 上传 → 逐行校验（可在线修正、跳过问题行或下载问题行重传）。
  2. 核对数量：每种商品数量 = 收件人数 × 每人份数，不一致时一键调整。
  3. 下单后按行发货，订单展示收件人数与发货 / 签收进度，可下载发货明细；电子卡券按名单短信发放。

5.4 礼包上架

  1. 供应商在供应商端组包并提交 → 商品库自动打「商品-礼包」标，状态「待挑选」。
  2. 运营挑选：挑中则打场景标、归入资源频道并上架，进入 AI 选品商品池。
  3. 修改组成 / 价格 / 开票明细 → 自动出池回到待挑选；下架或无库存 → 自动出池。

5.5 卡券

  1. 制卡在采发发外完成；运营导入电子卡卡密到卡池，或登记实体卡入库。
  2. 下单支付 → 电子卡分配卡密入「我的卡券」；实体卡按实物发货。
  3. 上传名单 → 分发草稿 → 确认后短信下发；员工在分采通商城兑换。

5.6 售后

  1. 已完成子单申请售后：选类型、原因，上传凭证。
  2. 供应商 48 小时内审核（京东 / 天猫等 API 来源走对方售后接口）；超时未审由平台介入（待确认）。
  3. 同意后：仅退款直接退款；退货退款 / 换货由用户选上门取件或自行寄回（面单识别回填）→ 退货中 → 供应商签收 → 原路退款或补发。

5.7 结算与开票

  1. 子单已完成 → 进入「未结算」（售后中的完成后再进入）。
  2. 财务在「账号与设置 › 结算与账单」多选子单 → 申请开票（抬头、税号、专票 / 普票）→ 各供应商按子单开具 → 已结算 · 开票中 → 已开票。首期不做对账单。

六、前台：发发福利一页

发发福利只有一个主页面：上半部是广告位、栏目、频道和 AI 对话框，下半部是随栏目与频道联动的 GUI；不再有独立的落地页和 AI 全屏页。

6.1 入口与身份

  • 侧栏一级菜单「发发福利」，与新建任务、资产库、IM 频道并列；点击进入一页，默认栏目「福利场景」、默认频道为「当前日期在上线时间内、排序最前」的场景。
  • 发发福利任务与通用任务共用侧栏「任务」列表，标题带发发福利标识。
  • 手机号 + 短信验证码注册即开通个人账户；个人账户各页面常驻「您当前使用的是个人用户」，价格位旁提示「升级企业版查看会员价」。

验收：点侧栏 1 秒内进入一页并选中首推场景；个人账户任何页面、任何接口都不含会员价。

6.2 广告位

  • 形态：页面顶部弧形卡片轮播（5 个可见位，中间为当前广告），卡片含封面图、标题、副标题和「广告 · 标签」角标，下方圆点指示。
  • 轮播：每 4.5 秒切换；对话框处于收缩态时暂停；系统「减少动效」时不自动轮播。
  • 点击：点侧边卡片先转到中间；点中间卡片执行跳转：指定栏目 + 频道（如「福利场景 › 新春年货节」）、商品详情或专题。
  • 内容由运营在「频道运营 › 广告位」配置，3–8 条，带投放时间。

6.3 固定栏目

  • 三个栏目「福利场景 / 商品资源 / 专家咨询」，纯文字分段开关，不带图标和副标题；栏目名称与顺序固定，不对运营开放。
  • 切栏目时：频道栏、对话框上下文与底部 GUI 同步切换；已输入的文字保留。切回福利场景时回到上次选中的场景频道。

6.4 运营频道

栏目 频道栏 首期频道（常驻 + 更多） 下方 GUI

6.5 AI 对话框

  • 对话框只保留自由输入，不在框内放二级 / 三级选项或填空模板；占位提示随栏目变化（如「日常采购直接说，例如「给 80 人买办公零食，人均 100」」）。
  • 底部工具栏：附件、场景上下文标签（如「场景：新春年货节 · 来自所选频道」或「常规采购 · 不限场景」）、有内容时的「清空」、发送。
  • 场景上下文来源：所选场景频道 > 资源频道上的运营场景标 > AI 从输入识别（提到春节、生日等自动切换并提示，可取消）> 常规采购。
  • 发送后在底部浮层完成前 2 轮反问（目标群体、人数与预算），答完进入任务对话页（第七章）；栏目、频道与上下文作为结构化参数传入。

6.6 底部联动 GUI

  • 福利场景 × 场景频道：标题「「场景名」场景运营」+ 上线时间；内容依次为 Banner 轮播（场景主视觉 + 运营专题）与 6 个场景专区（本季主推 / 场景礼盒 / 品牌专区 / 类目专场 / 场景卡券 / 爆款低至 X 折）、业务栏目（爆款限定 / 精选礼包 / 福利卡券）、卖点筛选、每行 5 个的商品网格。专区与网格只含带该场景标的商品，由规则出货。
  • 商品资源 × 资源频道：标题「「频道名」资源频道」+ 一行定位；类型筛选「全部 / 爆品 / 礼包 / 卡券」带数量（无商品的类型不显示）；商品网格中每张卡带类型角标。频道含哪些商品由运营按规则或手动圈选。
  • 专家咨询：场景推荐（模型生成，7.5）：主题 + 推荐理由、可点击发送的 3 条提问建议、4 个带推荐语的商品。
  • 商品卡：主图、两行标题、规格、毛利率（个人账户显示会员价说明）、价格 + 划线价、应用标签、已售 / 昨日订单 / 库存；悬停显示「集采询价 / 加入购物车 / 立即下单」，不提供铺货到商城。集采询价弹窗填数量区间与交期，提交到后台「集采询价」。

6.7 顶部搜索与底部对话框

  • 页头吸顶，中间常驻商品搜索框（「搜索商品、品类、品牌」）：聚焦只出下拉、不打开 AI（空词时为最近搜索 + 热门搜索；输入后为至多 5 个商品联想，末行「问发发：xxx」）。回车在当前页切为搜索结果视图：「‹ 返回{场景}」+ 结果数、顶部「让发发按『xxx』帮你配」横条（搜索词带人数或预算时高亮为采购需求）、范围（全部在售 / 当前场景货盘，默认全部）+ 类型 / 价位 / 品类 / 来源多选筛选与排序，商品卡可加购或「问发发」。
  • 页面下滑超过 520px 或在搜索结果页时，底部居中出现小对话框；点击向上展开为半屏浮层（约 720px），前 2 轮反问在浮层内完成，答完自动进入任务对话页。有进行中的任务时，小对话框左侧显示「↩ 任务名 · 人数 · 已选 N」，点击回到任务页，直接输入为追问，「+」开新任务。只输关键词时 AI 回一句结论 + 前 4 个商品 +「在页面查看全部」，两个入口不自动互转。
  • 收缩态时广告位暂停轮播；已输入内容不丢失。

6.8 验收

  • 切换栏目、频道时，对话框上下文标签与底部 GUI 同时变化，已输入文字保留。
  • 「更多场景 / 更多频道」下拉在对话框之上完整可见。
  • 资源频道类型筛选的数量与网格内容一致。
  • 搜索框聚焦不打开 AI；回车 1 秒内出结果视图，「返回」回到原场景页；下滑出现底部小对话框、滚动中不闪烁；浮层答完前 2 轮自动进入任务页。
  • 后台修改广告、频道、专区规则后前台刷新生效。

七、前台：AI 对话与任务栏

AI 负责理解需求、选品、答疑；选品结果放在右侧任务栏，下单支付跳 GUI。行为细节见《AI Prompt 设计 v2.0》。

7.1 任务对话页

  • 左侧对话、右侧任务栏（需求画像 → 选品结果 / 购物车）。任务栏默认 400px，左边缘可拖动（320–760px，对话区至少 640px），双击恢复；「加宽 / 恢复」「收起」，宽度按用户记忆。
  • 每轮回复 ≤ 2 句 + 1 张追问卡片，一次只问一个维度。追问卡片（参考 Claude / Gemini 的提问卡）：头部为「维度名」（合规类标「合规确认 · …」）+ 收窄进度条 +「当前范围：较宽 / 适中 / 已聚焦」（不展示问题编号、总轮数、候选数和目标规模；商品库 500 万+ SKU，过程数量只是估算；停止时 AI 说明原因）；问题加粗一行；选项为整行可点（单选圆点、名称、定性效果「范围明显收窄 / 略收窄 / 几乎不影响」，推荐项置顶并标「推荐」），点一下即提交；人数与预算为两组三段按钮；底部「跳过这一项」与「就这些，出结果」；已答的轮次折叠为一行「✓ 维度 + 答案 + 修改」。
  • 先识别意图（采购 / 找商品 / 咨询 / 不确定）。采购需求用 2–6 轮反问收窄：第 1 轮目标群体、第 2 轮人数与预算（必问，已说过的跳过），第 3 轮起按「最能缩小候选池」自动挑选库存、销量、利润率、发货仓、效期、售后、发放形式、商品偏好等维度。问法按商品库现有数据：库存只有有货 / 库存紧张 / 无货，无货始终过滤，只问「库存紧张的要不要」；发货只分电商仓（京东、猫超自营仓，发货更快）与商家仓（其余来源及猫超部分商品），只问「要不要只选电商仓」，不承诺具体时效；效期只有部分食品标注，只在候选含已标注效期的食品时问，并提供「未标注的保留」选项。选品结果每个 SKU 显示发货仓与「库存紧张」标记，筛选增加「发货仓」。候选达到目标规模（默认 80，后台按场景配置，对用户不可见）、问满 6 轮或用户点「就这些，出结果」时停止；一句话多个条件一次生效只算 1 轮；候选 < 10 时指出卡住的条件并给放宽选项，不自动放宽。反问阶段右侧为「需求画像」：当前范围档位、合规说明（已排除品类与依据）、条件标签（可改可删）与排在前面的商品。

7.2 执行步骤与自检循环

  • 每次出方案走「理解 → 召回 → 按条件收窄 → 自检 → 修正」内循环，最多 3 轮、总耗时 ≤ 8 秒。
  • 自检项：采购成本 ≤ 可用采购预算、毛利率 ≥ 目标、库存与起订量、主商品不重复、红线。
  • 前端展示可折叠的步骤条：未通过项用橙色标出（如「第 1 轮：福满年货礼包采购成本 ¥298，毛利 1% < 15%」），完成后标题为「已完成 N 个步骤 · 自检循环 k 轮」。
  • 参数标签：场景、用途、人数、客户预算、口径（如「对客 · 预留 15%」）、可用采购。

7.3 选品结果与利润

  • 输出全部满足条件的 SKU，不截断；爆品 / 礼包 / 卡券都是 SKU 维度（由供应商录入时指定，礼包为供应商整箱供应的一个 SKU，AI 不拼套装）；每个 SKU 单价 ≤ 每人可用采购预算。顶部显示需求条件与「继续缩小范围」；筛选为类型 / 价位 / 品类 / 来源四组多选（组内「或」、组间「且」，选项带数量），排序为推荐 / 价格 / 销量 / 毛利。
  • 结果支持多选与「全选当前结果」，推荐 SKU 默认勾选；点商品看详情；底栏显示已选 SKU 数、每人合计与总额，多选合计超出每人预算时提示。
  • 企业账户利润区：口径标签、采购成本、建议对客价、每人利润、毛利率、预计总利润；低于目标毛利率时橙色提示（卡券提示「卡券折扣有限」）。自用口径显示「自用 · 不留利润」。个人账户不显示。
  • 按钮：「加购已选 · 各 N 份」「立即购买」「导出清单」；一件未选时置灰。
  • 快捷调整：继续缩小范围 / 只看礼包 / 员工自选（卡券）/ 调整利润（留 10% / 15% / 20% / 不留利润）/ 去购物车；任一调整重新进入内循环，其余参数保留。

7.5 场景推荐（模型调用）

  • 触发：进入一页、切换栏目或频道、场景上下文变化；同一组合在缓存期内不重复调用。
  • 候选商品由运营规则给出（≤ 20 个），模型只在候选内挑 4 个、排序并写推荐语；输出主题、理由、提问建议与预填人数 / 预算；文字不含价格。
  • 1.5 秒未返回或校验失败时用运营默认文案与规则前 4 个商品。
  • 展示位置：专家咨询栏目底部；其他栏目可在后台开启为运营页顶部模块（待确认）。

7.6 合规确认与依据展示（10-22 新增）

政企福利采购受 53 号文（央企采购管理）、全总《基层工会经费收支管理办法》、各省工会经费细则和客户内规约束。前台把合规做进选品工作流，由规则引擎确定性执行，AI 只解释并引用依据。

环节 前台表现
合规确认 目标群体后出一张「合规确认」卡片，三组按钮：客户类型（党政机关 / 事业单位 / 央企 / 地方国企 / 民营企业 / 外资企业 / 社会组织 / 其他·不确定）、「这笔福利从哪项预算出」（工会经费 / 职工福利费 / 客户礼品·业务招待 / 员工自付 / 不确定）、客户所在地。不计入问题数；需求里已说清的跳过。列表里没有的单位可直接输入（如「市属城投」）由 AI 归类；选「其他 / 不确定」或跳过时按公款口径从严
硬过滤 确认后 AI 说「已按『地方国企 · 工会经费 · 浙江』套用合规规则：合规已排除：酒水、储值 / 购物卡」；被排除商品不进入候选，不参与放宽
额度校验 工会经费且所在地有限额细则时，人数预算后追问「今年其他节日已发过多少」，选项下显示剩余额度；超额时给「按剩余额度调整人均」「改由福利费列支（需客户确认）」两个选项；生日慰问按每次限额直接校验
依据展示 需求画像与选品结果顶部显示蓝色合规说明：合规标签、已排除品类、依据政策名称；「查看命中规则」「导出采购留痕包」（公款单位）
限额提示 央企 / 地方国企本单金额超过公开采购限额（默认 ¥50,000，客户内规可覆盖）时，结果页显示红色提示与「导出比价单」；商品偏好增加「优先帮扶地区产品」，商品行标「帮扶产品」
红线 拆单规避审批、发票与实物不符一律拒绝并给替代做法

政策与规则由运营在后台「专家咨询知识库 › 合规与采购政策 / 合规规则」维护（见 10.5），前台不硬编码任何金额与品类。

7.7 验收

  • 只说「帮我配一下」时第 1 轮问目标群体、第 2 轮问人数与预算；已给的参数不重复追问；过程中不出现精确候选数、目标规模和问题编号，出结果后才显示实际 SKU 数；前 2 轮不提供「出结果」；结果数不被截断。
  • 客户预算人均 300、利润 15% 时，结果中每个 SKU 单价 ≤ 255，建议对客价 ≤ 300。
  • 自检拦下的商品在结论里说明替换；3 轮仍不足时告知最高可留利润，不强凑。
  • 个人账户不出现采购成本、利润、毛利率与「调整利润」。
  • 场景推荐商品 100% 来自候选，文字无价格。
  • 合规：「央企 / 地方国企 / 机关 / 事业单位 / 其他」或「工会经费」时候选里不出现酒水与储值 / 购物卡；浙江工会经费节日慰问必问已发金额，超额时不自动替用户选；跳过合规确认时从严并写明假设；结果页合规说明的依据与后台生效政策一致。
  • 央企 / 地方国企本单超公开采购限额时显示提示与「导出比价单」；要求拆单时 AI 拒绝。

八、前台：交易与账户

交易页全部是独立页，仅企业账户可结算；一个订单可含多个供应商的商品，下单后才拆单。

8.1 购物车

  • 按商品来源（京东 / 天猫超市 / 天猫优品 / 平台精选 / 入驻商家 / 卡券）分组，仅展示不拆单；全选、按供应商全选、单品勾选，可跨供应商组合下单。
  • 数量 − / + 与手动输入（1–99999，非数字过滤）、单品删除、批量删除；右侧只汇总已选（件数 / 供应商数 / 合计）。对话右侧购物车同样支持。
  • 加购校验起订量、限购、库存；下架或无库存置灰；变价标出。「立即下单」只结算本次商品。

8.2 确认订单与收银台

  • 收货：单一地址或名单代发（模板 → 上传 → 逐行校验 → 核对数量，≤ 5000 行）；电子卡无需地址。名单未通过或数量不一致不可提交。
  • 拆单预览：子单来源、商品、金额、运费、预计发货时间。
  • 提交生成 1 个主单 + N 个子单（主单号-1 / -2…）。收银台：① 合并支付（一种支付方式）；② 按子单分别支付（每个子单可选不同方式）。主单未全付时剩余子单可单独支付或取消；30 分钟未付自动关闭。
  • 支付方式：在线支付、预付款、活动账户；按实际支付对象校验余额；活动账户仅限实物子单，合并支付含电子卡时提示「可改用按子单分别支付」。
  • 金额 ≥ 企业审批阈值时进入「待审批」，通过后才可支付，驳回关闭。

8.3 订单列表与子单详情

  • 列表以主单为卡片，卡内逐行展示子单；状态 Tab：全部 / 待审批 / 待支付 / 待发货 / 待收货 / 已完成 / 售后 / 已取消，按子单计数。
  • 筛选：订单号、下单信息（商品 / 供应商）、下单时间（快捷 + 自定义起止）、下单人（手动输入模糊匹配）、收货方式；与 Tab 叠加，可一键重置。
  • 子单状态与操作：待支付（支付、取消、合并支付剩余）→ 待发货（催发货、取消并退款）→ 已发货（查看物流、确认收货）→ 已完成（申请售后、去结算开票、再来一单）；支线售后中、已取消。
  • 子单详情：状态进度条 + 当前操作；① 订单明细；② 下单人明细与收货信息；③ 发货明细（包裹、运单号、物流节点；名单代发展示收件人进度表可下载）；④ 售后明细；右侧可切换同主单其他子单。
  • 物流节点：所有已发货、已完成子单及退货中售后可查，倒序，最新节点高亮。

8.4 售后

  • 已完成子单可申请：类型（退货退款 / 仅退款 / 换货）、原因、至少 1 张凭证（≤ 6 张）为必填；申请数量（自动算退款金额）、问题描述可选。礼包整包售后；卡券未兑换可按张退。
  • 供应商 48 小时内审核（可撤销）→ 驳回（展示原因，可补充凭证再申请）或同意。
  • 退货退款 / 换货同意后选寄回方式：上门取件（地址、联系人、预约日期与时段，系统下单回填运单）或自行寄回（物流公司、运单号；支持上传面单 / 寄件截图自动识别回填，失败提示手动填写，面单存为凭证），运费由供应商承担 → 退货中 → 供应商签收 → 原路退款或补发。
  • 退款原路退回：在线支付回原通道；预付款、活动账户回各自余额并写入流水；已开票提示红冲。

8.5 结算与开票（首期不做对账单）

  • 子单已完成后进入「未结算」；账单列表分未结算 / 已结算，顶部显示金额与子单数；字段：子单号、供应商、商品、完成时间、支付方式、金额、状态。
  • 未结算支持单选 / 全选，底部汇总「已选 N 个子单 · 涉及 M 个供应商 · 合计」；「申请开票」确认抬头、税号、金额、专票 / 普票，由各供应商按子单开具；状态「已结算 · 开票中」→「已开票」，可下载电子发票。
  • 礼包按子商品行开票；活动账户金额作同票折扣行；卡券开票规则未定前不开放。

8.6 账号与设置（含财务账户）

  • 版式沿用 QA「账号与设置」：左侧设置导航 + 右侧内容卡。导航：账户与权益（我的订阅 / 账号信息 / 平台权益）、财务与账单（财务账户 / 结算与账单）、组织与协作、业务偏好（新增默认预算口径与默认利润率）、数据与支持。资产库不再展示财务账户入口。
  • 侧栏底部账户弹窗：企业 / 团队下方放三个入口——当前权益（个人版 / 企业版）、采购车（件数角标，>99 显示 99+）、预付款（余额默认「¥ ****」，点眼睛图标显示）；其余为账号与设置、帮助中心、退出登录。
  • 财务账户：① 预付款：余额、冻结金额、充值；不支持用户主动退款；② 活动账户：余额、有效期、使用规则；③ 在线支付开通状态；资金流水可按账户筛选、导出。

8.7 预付款充值

方式 用户操作 规则
汇款智能认账（推荐） 选汇款银行（民生 / 招商），查看开户名称、开户银行、专属汇款账号，复制账号信息，通过网银或柜台转账 专属账号一企一号；到账自动识别入账，无需备注；金额不限；个人账户汇入原路退回

  • 按批次和单张查看：未分发 / 已分发 / 已兑换 / 已过期 / 已作废。
  • 分发：上传姓名 + 手机号 → 分发草稿 → 确认后短信下发兑换链接；也可导出卡密自行发放。兑换在分采通商城完成。
  • 验收：确认后才发送；同一张券只能兑换一次。

9.2 订单、售后与开票（新增）

  • 子单发货：填物流公司与运单号；名单代发按行发货，支持批量导入运单。收到催发货提醒。

  • 开票：接收采购商的开票申请，上传电子发票或对接开票接口；礼包按子商品行开具。

  • 场景频道：场景名、场景标、上线时间段、排序、是否常驻频道栏、角标（如「预热中」）、一行说明；场景层 AI 配置（典型需求、默认对象、附加槽位、召回偏好、预算档位、物流截止日）。

  • 场景推荐：按栏目 × 频道配置候选规则、默认标题与预置提问（模型超时时使用）、缓存时长；可查看模型输出抽样。

10.3 交易管理

  • 子单与物流：供应链推送状态、发货与退货物流轨迹、名单代发明细；推送失败可重推。
  • 售后监管与介入：全部售后单可查；供应商超 48 小时未审、用户申诉的进入介入队列，平台可代为审核、触发退款。
  • 集采询价：询价单（商品、数量区间、交期、企业、联系人）、负责人、状态（待报价 → 已报价 → 已成单 / 关闭）、报价回复；专家咨询「项目定制」的线索可一键转询价单。

10.4 财务与会员

  • 汇款认账：银行入账流水按专属账号自动匹配企业并入预付款；匹配失败进入「待认领」人工处理；个人账户汇入标记退回。在线充值记录、充值收据。
  • 专属汇款账号：企业认证通过后自动分配（民生 / 招商各一个），可冻结。
  • 预付款退回：用户无自助入口；企业线下申请后由财务在后台办理并双人复核（待确认）。
  • 结算管理：按子单查看未结算 / 已结算与开票状态，口径同前台；开票监管：供应商超时未开提醒、红冲。
  • 企业认证审核、企业与成员、充值赠送规则、活动账户流水同 v1.0。

  • Agent 运营：对话日志；工具调用审计（每轮自检结果与修正内容）；红线告警（个人账户触发下单、池外商品、会员价或利润泄露给个人账户）；评测集一键回归。

知识库新增两个栏目（10-22）：「专家咨询知识库」由「知识条目 / 未命中问题」扩为「知识条目 / 合规与采购政策 / 合规规则 / 未命中问题」。「合规与采购政策」归档政策原文（国家 / 地方 / 行业 / 客户内规），带文号、适用对象、生效与复核日期、状态（草稿 / 生效中 / 待复核 / 已废止）；「合规规则」是从政策拆出的可执行规则，前台选品工作流直接读取。详见《运营管理后台 PRD》知识库章节。

十一、AI 能力要求与工具

AI 负责理解需求、选品和问答，不在对话内完成下单支付；召回、排序、组方案、自检由规则服务完成，模型不自行挑选、增删或改价商品。

11.1 红线（违反即 P0 缺陷）

  1. 个人账户不能下单：只引导升级，不调用结算工具。
  2. 只用 AI 选品商品池内、当前栏目 / 频道 / 场景范围内的商品；不提工具未返回的商品。
  3. 价格、库存、时效只引用工具返回值。
  4. 个人账户只展示市场价，不透露会员价、采购成本、利润或差额。
  5. 下单、支付跳转 GUI 独立页；发券、售后、开票先草稿后确认。
  6. 无工具支撑的需求（定制、大额议价等）不承诺，转专家。
  7. 选品不得超出客户预算，不得悄悄压低服务商利润。

11.2 工具（CUI 底座接口）

11.3 验收

上线前跑《AI Prompt 设计 v2.0》评测集：红线类 100%，其余 ≥ 90%；AI 响应首字 ≤ 3 秒，出方案（含自检循环）≤ 8 秒，场景推荐 ≤ 1.5 秒（建议值）。

12.2 非功能需求

  • 性能：一页首屏 ≤ 2 秒；切栏目 / 频道后底部 GUI ≤ 1 秒；滚动收缩不掉帧；子单发货后 5 分钟内可见运单号。
  • 合规与安全：个人账户在接口层拦截下单；会员价、采购成本、利润字段对个人账户不下发；卡密、营业执照加密存储；专属汇款账号仅本企业可见。
  • 资金：支付与扣款幂等；平台不自建资金池，在线支付经第三方分账。
  • 可用性：AI 不可用时一页 GUI 与交易流程不受影响，场景推荐降级为规则结果；供应链推送失败自动重试并告警。
  • 体验：支持「减少动效」；键盘可操作栏目、频道与下拉；视觉按《采发发（88buys）官网视觉设计规范 v1.0》。
  • 端：Web / PC 客户端。
