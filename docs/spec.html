一、概述

首期交付「从进入到结算开票」的最小闭环：32 个用户故事（US-21 本期取消），2026-11-20 上线。本版以 Demo「Beta 0.3 · 一页融合」为准，配套《发发福利 PRD v2.0（一页融合版）》、《运营管理后台 PRD v1.1》与《发发福利 AI Prompt 设计 v2.1》；口径不一致时以 PRD 为准。

  • 产品形态：发发福利是采发发侧栏一级应用，只有一个主页面——广告位、固定栏目（福利场景 / 商品资源 / 专家咨询）、运营频道、AI 对话框、底部联动 GUI；页头常驻商品搜索框；下滑过首屏后 AI 对话框收为底部小对话框，点击展开。
  • 合规红线：只有企业账户能下单；个人账户只看市场价，不见会员价、采购成本和利润。
  • 服务商口径：用户说的预算默认是客户预算，选品先扣目标利润。
  • 本期不做：C 端商城与移动端；企业对账单；个人下单；多级审批；卡券制卡；储值卡；礼包部分 / 批量售后；合并开票；对外开放接口；铺货到商城；预付款退回（用户与后台均不支持）；下单后修改收货地址。

主流程（每步对应第二节故事）

  1. 进入：侧栏进入一页，默认福利场景 · 当季首推场景。
  2. 找货：选栏目与频道浏览底部 GUI，或用顶部搜索框直接搜商品，或在对话框说需求，或点场景推荐。
  3. AI 方案：先识别意图，采购需求用 2–6 轮反问按群体、预算、库存状态、销量、利润率、发货仓、效期、售后等维度缩小范围，再输出全部满足条件的 SKU 与利润，标出 1 个推荐 SKU；爆品 / 礼包 / 卡券都是 SKU 维度（礼包由供应商整箱供应），AI 不拼套装。
  4. 加购：勾选加购或立即购买。
  5. 下单支付：确认订单 → 生成主单并拆子单 → 合并或分子单支付。
  6. 履约：按来源发货、名单代发、卡券分发。
  7. 售后：供应商审核，寄回，原路退款。
  8. 结算开票：已完成子单多选申请开票。

三、进入与找货（US-01–04、07、08、22、23、25、33）

用户从侧栏进入一页，通过栏目和频道找货；对话框与底部 GUI 始终在同一页面。

功能要点

  • 一页结构（US-01）：吸顶页头（含商品搜索框）→ 广告位 → 标题 → 固定栏目 → 运营频道 → AI 对话框 → 底部联动 GUI。
  • 固定栏目（US-04）：福利场景 / 商品资源 / 专家咨询，纯文字分段开关；不对运营开放配置。
  • 场景频道（US-03、07）：常驻新春年货节 / 生日补贴 / 餐补随心兑，其余在「更多场景」下拉；选中后底部按后台页面装修渲染：丰富型为 Banner 轮播 + 6 个场景专区，精简型为 Banner + 4 个专题方块，可选核心品牌；下方为业务栏目与商品网格。场景商品来自后台「商品来源」（商品池 / 专题 / 规则 / 手动矫正），场景过有效期自动下线。
  • 资源频道（US-08）：常驻电商精选（京东自营）/ 天猫超市 / 天猫优品 / 零食专场 / 粮油专场，其余在「更多频道」；底部按频道页面装修展示 Banner、专题方块与核心品牌，再展示频道商品，可按全部 / 爆品 / 礼包 / 卡券（商品类型，由供应商指定）筛选。
  • 对话框：自由输入 + 场景上下文标签；输入框提示语与下方 1–6 条引导问句由后台按场景 / 频道配置，点击问句直接发送，填空句的可改值以「［］」标出；「+」专家技能显示即将上线。
  • 广告位（US-25）：弧形卡片轮播，4.5 秒切换；点中间卡跳转栏目 + 频道、商品或专题。
  • 搜索框（US-22）：页头常驻商品搜索框（占位「搜索商品、品类、品牌」），聚焦只出下拉、不开 AI：空词时为最近搜索 + 热门搜索；输入时为「搜索『xxx』」+ 至多 5 个商品联想，末行「问发发：xxx」。下滑 > 520px 后页头第二行常驻栏目与频道，AI 对话框收为底部居中的小对话框。
  • 搜索结果（US-22）：回车后在当前页切为结果视图——「‹ 返回{场景}」+ 结果数；顶部横条「让发发按『xxx』帮你配 →」；筛选为范围（全部在售 / 当前场景货盘，默认全部）+ 类型 / 价位 / 品类 / 来源四组多选（选项带数量），排序综合 / 销量 / 价格；商品卡可直接加购或「问发发」，当前场景货盘内的商品带场景小标。结果为空时提示换词或交给发发。
  • 底部小对话框（US-06、22）：滚过首屏或在搜索结果页时出现。点击后向上展开为半屏浮层（约 720px），前 2 轮反问（目标群体、人数与预算）在浮层内完成；答完后自动进入任务工作台，左侧继续反问、右侧为需求画像，停止反问后右侧变为选品结果。浮层右上角可「展开大对话框」回到顶部。
  • 入口互转：不自动互转。搜索词带人数或预算时照常出结果，横条高亮为「看起来是采购需求，让发发按『120 人 · 人均 300』配」；在对话框只输关键词时，AI 给一句结论 + 前 4 个商品 +「在页面查看全部 N 个 →」。
  • 任务延续：有进行中的任务时，底部小对话框左侧显示「↩ 员工年货 · 120 人 · 已选 N」，点击回工作台；直接输入为对当前任务追问；「+」开新任务。商品卡「问发发」把该商品带入浮层。
  • 价格与身份（US-23）：个人账户看市场价与「升级企业版查看会员价」，企业账户看会员价与划线市场价。
  • 集采询价（US-33）：商品卡悬停「集采询价」，弹窗填数量区间与交期，提交到后台。

验收标准

  • [ ] 点侧栏 1 秒内进入一页，2 秒内首屏完整；2026-11-20 至春节档内默认选中「福利场景 · 新春年货节」
  • [ ] 切换栏目或频道后 1 秒内底部 GUI 刷新，对话框上下文标签同步变化，已输入文字保留
  • [ ] 「更多场景 / 更多频道」下拉在对话框之上完整可见；选中下拉内频道后按钮显示频道名并高亮
  • [ ] 场景页的专区与网格只含该场景「商品来源」算出的在售商品；空坑位不展示；过有效期的场景不再出现在场景频道栏；资源频道类型筛选数量与网格一致，无商品的类型不显示
  • [ ] 后台修改广告、频道名称 / 顺序 / 常驻、引导词、页面装修并发布后，前台 1 分钟内生效
  • [ ] 搜索框聚焦不打开 AI；回车 1 秒内出结果视图，「返回」回到原场景页；下滑出现底部小对话框、滚动中不闪烁；在浮层答完人数和预算后自动进入工作台；收缩时广告暂停轮播
  • [ ] 个人账户任何页面、任何接口都不返回会员价；各页面显示身份提示
  • [ ] 集采询价提交后后台可见，状态为「待报价」

四、AI 推荐、利润、场景推荐与专家咨询（US-05、06、26–28）

AI 只理解需求和写结论，商品由规则服务召回、组方案和自检；企业账户方案默认按客户预算留出利润。

功能要点

  • AI 方案（US-06）：先识别意图（采购 / 找商品 / 咨询 / 不确定）；采购需求进入 2–6 轮反问收窄——第 1 轮目标群体、第 2 轮人数与预算（必问，已说过的跳过），第 3 轮起按「最能缩小候选池」自动挑维度（销量 / 利润率 / 发货仓：只选电商仓（京东、猫超自营仓）还是商家仓也可以 / 效期（只对标注了效期的食品）/ 售后 / 发放形式 / 偏好；库存不问用户，按强制规则：无货始终过滤，有库存数的要求 ≥ 人数 × 份数，只有状态的人数 ≥ 50 时不选库存紧张），每轮 3–4 个选项带定性效果（范围明显收窄 / 略收窄 / 几乎不影响）并标推荐，另有「跳过」「就这些，出结果」；追问以卡片呈现（参考 Claude / Gemini 提问卡）：头部为「维度名」+ 收窄进度条 +「当前范围：较宽 / 适中 / 已聚焦」（不展示问题编号、总轮数、候选数与目标规模，停止时说明原因），选项整行可点、点即提交，推荐项置顶，已答轮次折叠为「✓ 维度 · 答案 · 修改」；一句话多条件一次生效算 1 轮；候选 < 10 时指出卡住的条件并给放宽选项。第 2 轮后进入工作台，右侧「需求画像」显示当前范围档位、合规说明、条件标签（可改 / 可删），提问阶段不展示任何商品。候选达到目标规模（默认 80，后台按场景配，对用户不可见）、问满 6 轮或用户要求时停止；右侧输出全部满足条件的 SKU（不截断）：按商品类型（爆品 / 礼包 / 卡券）、价位、品类、来源四组多选筛选（组内「或」、组间「且」，选项带数量），可按推荐 / 价格 / 销量 / 毛利排序；结果支持多选与「全选当前结果」，推荐 SKU 默认勾选；底栏显示已选 SKU 数、每人合计与总额，多选合计超出每人预算时提示；「加购已选」按每个 SKU × 人数加入购物车，也可立即购买或导出清单；快捷调整「继续缩小范围 / 只看礼包 / 员工自选（卡券）/ 调整利润 / 去购物车」。
  • 利润差价（US-26）：可用采购预算 = 客户预算 × (1 − 目标毛利率)；选品结果按已选 SKU 显示采购成本、建议对客价、每人利润、毛利率与总利润；「自己员工」为自用口径不留利润；卡券利润 = 面值 − 会员价。
  • 自检循环（US-27）：理解 → 召回 → 组方案 → 自检 → 修正，最多 3 轮 / 8 秒；步骤条展示每轮结果，未通过项橙色。
  • 反问与选择推荐：采购需求用 2–6 轮反问逐步收窄，每轮只问 1 个维度；意图不明或涉及合规判断时另问；给用户多个选项（方案、价位、发放形式）时，标出 1 个「推荐」并写一句理由。
  • 选品清单：用户要「选一批商品 / 出选品单」时不组方案，先多轮收窄，再输出全部满足条件的商品（不设上限，靠收窄控制规模），可筛选、可导出、可加购。
  • 合规约束：客户为政府、事业单位、国企或使用工会经费时，不推荐烟酒、奢侈品和购物卡 / 现金类卡券；不协助拆单规避审批、品名不符的发票或虚报价格；政策类问题只给依据并提示以当地规定为准。
  • 场景推荐（US-28）：独立模型调用，在规则候选内挑 4 个商品、写推荐语与 3 条提问建议；超时降级为规则结果。
  • 专家咨询（US-05）：福利咨询走知识库（答案 ≤ 4 句 + 来源）；知识库以外或定制需求引导拨打 400 热线或提交需求表单，表单推送后台「咨询需求单」与钉钉群，不报价；经营概况分析仅企业管理员与财务可用。
  • 合规工作流（US-34）：目标群体后一张「合规确认」卡片问客户类型（8 类，含「其他 / 不确定」）、福利预算科目（工会经费 / 职工福利费 / 客户礼品·业务招待 / 员工自付 / 不确定）、所在地，不计入问题数；规则引擎按后台「合规规则」硬过滤（先于计数，不参与放宽）；有地方限额时追问已发金额并校验，超额给「调整预算 / 换科目」；结果页显示合规说明与依据、「查看命中规则」「导出采购留痕包」；央企 / 地方国企超公开采购限额时提示并可导出三家比价单。
  • 数量口径：商品库 500 万+ SKU，收窄只在当前场景货盘内做；过程数量由搜索引擎聚合估算，只用于停止判断和档位展示；精确计数与排序只在出结果时做一次并分页。
  • 用途与品类适配（US-06）：按目标群体定用途（自用福利 / 对外送礼 / 慰问），按后台场景配置的首选 / 慎推品类排序；慎推品类不进前 10、不作为推荐 SKU；品类适配度权重高于毛利。
  • Agent 六步循环（US-06）：分解目标 → 选下一步 → 调工具 → 检查结果 → 更新状态 → 回到选下一步；需求画像顶部显示任务清单（合规确认 / 选品 / 下单方式 / 交期 / 开票），用户已说清的直接标已确认；每次条件变化后检查合规、库存、预算与额度；结果末尾列出剩余子任务；任务状态跨会话保存。

验收标准

  • [ ] 只给人数时 AI 只追问预算；第 2 轮仍缺预算按标准档出方案并说明假设
  • [ ] 客户预算人均 300、目标 15% 时：选品结果中每个 SKU 单价 ≤ 255，建议对客价 ≤ 300
  • [ ] 点「调整利润 › 留 20%」后重新出方案，人数、客户预算保留；「不留利润」后显示自用口径
  • [ ] 第 1 轮入选商品毛利低于目标时被自检拦下并替换，结论中说明；3 轮仍不足时告知最高可留利润，不强凑
  • [ ] 个人账户方案只显示市场价，不出现采购成本、利润、毛利率与「调整利润」
  • [ ] 「换一批」返回与上一批不同的方案；商品资源栏目只用当前频道内商品
  • [ ] 场景推荐商品 100% 来自候选，文字不含价格；1.5 秒未返回时展示规则结果
  • [ ] 知识库外问题不编造，展示 400 热线与需求表单入口；表单提交后后台「咨询需求单」可见、钉钉群收到通知
  • [ ] 个人账户申请经营概况分析时不调用数据，引导升级
  • [ ] 只说「帮我配一下」时第 1 轮问目标群体、第 2 轮问人数与预算；过程中不出现精确候选数、目标规模和问题编号，右侧需求画像只显示范围档位；候选达到目标规模、满 6 轮或点「就这些，出结果」时停止；前 2 轮不提供出结果；一句话多条件只算 1 轮；结果数不被截断
  • [ ] 每次给出 2 个及以上选项时，恰好 1 个标「推荐」，理由 ≤ 20 字且引用用户说过的条件
  • [ ] 「帮我选一批年货商品」返回 45–55 个商品；候选不足 45 个时返回全部并说明实际数量与可放宽的条件
  • [ ] 用户说明客户为机关 / 国企或用工会经费时，方案与清单中不出现烟酒、奢侈品、购物卡；要求拆单规避审批或开品名不符的发票时拒绝并说明
  • [ ] 央企 + 工会经费 + 浙江、年货场景：候选无酒水与储值 / 购物卡；追问今年已发节日慰问金额并显示剩余额度；结果页依据列出全总办法、浙江细则与 53 号文
  • [ ] 浙江工会经费生日场景人均 500：提示每人每次 ≤ ¥300，只保留蛋糕类，由用户选择调整预算或换科目
  • [ ] 输入「市属城投」识别为地方国企；合规确认点「跳过」按公款口径从严并写明假设
  • [ ] 后台政策转「待复核」后，对应规则只提示不拦截；规则启停即时生效于前台
  • [ ] 「120 人职工年货，人均 200」与「人均 300」：前 10 与推荐 SKU 不含茶叶、酒水、高端滋补，结果说明里有排序依据；送客户年货时茶叶可进前列
  • [ ] 提问阶段右侧只有需求画像（范围、合规、条件），对话与右侧都不出现商品；点「就这些，出结果」或自动停止后才出选品结果
  • [ ] 追问里不出现库存；300 人结果无库存紧张商品并告知自动排除数；30 人时库存紧张商品保留并标注
  • [ ] 「300 人员工年货，人均 300，名单代发，1 月 20 日前到货，开专票」：任务清单里下单方式、交期、开票已确认；未说清时结果末尾列出待确认子任务

五、加购、下单支付与履约（US-09–17、24、29–31）

一笔订单可含多个供应商的商品，提交后生成主单并按来源拆子单；只有企业账户能进入结算。

功能要点

  • 加购（US-09）：方案内勾选加购，每件数量 = 人数；单品默认 1；校验起订量、限购、库存。
  • 购物车（US-10）：按来源分组（不拆单）；全选 / 按供应商全选 / 单选；数量 ± 与手动输入 1–99999；单品与批量删除；只汇总已选。
  • 确认订单（US-14、29）：单地址或名单代发（模板 → 上传 → 逐行校验 → 核对数量）；拆单预览；提交生成主单与子单（主单号-1 / -2…）；提交后不支持修改收货地址，需取消重下，确认页醒目提示。
  • 收银台（US-11、12、24、30）：合并支付或按子单分别支付；在线支付 / 预付款 / 活动账户；活动账户仅实物子单；不允许单笔混合支付；30 分钟未付关闭；超阈值先审批。
  • 升级（US-13）：个人账户点任何下单入口弹升级引导，上传营业执照，3 个工作日内审核，通过后一键回到结算。
  • 履约（US-15–17）：只按来源拆单；礼包整包进入其供应商子单；电子卡从卡池分配卡密；所有已发货子单可查物流节点（倒序、最新高亮）。
  • 订单（US-31）：主单卡片内逐行展示子单；状态 Tab 按子单计数；筛选订单号、下单信息、下单时间（快捷 + 自定义）、下单人（手输模糊）、收货方式；子单详情含订单 / 下单人 / 发货 / 售后明细。
  • 会员价与商品池定价规则（US-35）：会员价 = 接口价 × 当前场景 / 频道所绑商品池在本业务系统下的定价规则（按类目 / 品牌 / 货源 / 利润率区间命中加价率，多池取最低价，未入池用平台默认），不叠加会员等级折扣；全站搜索用平台默认加价并提示场景更低价；购物车按「商品 + 价格来源」分行；结算前重新取价；确认订单页按地址显示运费与应付；订单保存价格来源与模板版本快照。

验收标准

  • [ ] 整方案加购后购物车每个商品数量 = 人数 × 单人份数；「立即下单」不影响购物车其他商品
  • [ ] 购物车分组数 = 拆单预览子单数 = 实际子单数；金额一致
  • [ ] 数量输入非数字被过滤，小于 1 按 1 处理；无库存商品不可勾选
  • [ ] 名单有错误行或数量与名单不一致时不能提交；修正后可提交；下单后可下载发货明细
  • [ ] 主单未付时可只付其中一个子单；剩余子单可在订单列表继续支付或取消
  • [ ] 同一订单重复点支付只扣一次；超阈值未审批前不扣款，驳回后关闭并释放库存
  • [ ] 含电子卡的子单不能选活动账户；不能同时扣活动账户与预付款
  • [ ] 个人用户点任何下单入口一定出现升级引导且不生成订单
  • [ ] 含 3 个来源的订单支付后生成 3 个子单；子单发货后 5 分钟内可见运单号与节点
  • [ ] 筛选与状态 Tab 叠加生效，Tab 计数随筛选变化；自定义日期后快捷项失效
  • [ ] 同一商品在「新春年货节」与「生日关怀」显示的会员价与各自模板一致；从两个场景加购在购物车显示为两行并标注定价来源
  • [ ] 确认订单页显示运费与应付；京东 / 天猫超市包邮；提交后子单金额含运费
  • [ ] 后台改模板或单品改价后 1 分钟内前台生效，已下单订单价格不变；低于底价的单品改价无法保存

六、售后、结算开票与账户（US-18–20、32）

售后由供应商审核、平台可介入；首期不做对账单，只对已完成子单结算开票；财务入口统一在「账号与设置」。

功能要点

  • 售后（US-18）：类型（退货退款 / 仅退款 / 换货）、原因、凭证 1–6 张必填；供应商 48 小时内审核；退货类同意后选上门取件（地址、联系人、预约时段）或自行寄回（物流公司 + 运单号，支持面单识别回填）→ 退货中 → 签收 → 退款或补发。
  • 退款（US-19）：在线支付回原通道并回退分账；预付款、活动账户回各自余额并写流水；已开票提示红冲。
  • 结算开票（US-20）：已完成子单进入未结算；多选后申请开票（抬头、税号、专票 / 普票），各供应商按子单开具；状态已结算 · 开票中 → 已开票；礼包按子商品行；活动账户金额同票折扣。
  • 账户（US-32）：QA 式「账号与设置」；账户弹窗含当前权益、采购车（件数）、预付款（余额默认隐藏）；财务账户含预付款、活动账户、在线支付状态与资金流水；业务偏好可设默认预算口径与默认利润率。
  • 预付款充值（US-32）：汇款智能认账（选银行、查看专属账号与企业专属汇款识别码、复制账号信息，到账按识别码自动入账，后台不做人工匹配）或微信 / 支付宝在线充值（金额 → 渠道 → 二维码）；预付款不支持退回（用户与后台均无入口）。

验收标准

  • [ ] 售后未填类型、原因或无凭证时不能提交；凭证最多 6 张
  • [ ] 仅退款同意后直接退款；退货类同意后出现寄回方式选择
  • [ ] 上传面单可识别并回填物流公司与运单号；识别失败提示手动填写；面单出现在售后明细
  • [ ] 售后只影响对应子单；预付款订单退款后流水实时可见；礼包只能整包售后
  • [ ] 供应商超 48 小时未审的售后进入平台介入队列
  • [ ] 未完成子单不能申请开票；多选汇总的子单数、供应商数与合计正确；申请后状态变为「已结算 · 开票中」
  • [ ] 活动账户订单发票折让金额 = 活动账户支付金额；礼包发票与供应商开票明细一致
  • [ ] 弹窗预付款余额默认隐藏，点眼睛显示，与财务账户页同步
  • [ ] 汇款后系统自动入账并写流水；在线充值超单笔限额时提示改用汇款；财务账户无预付款退款入口
