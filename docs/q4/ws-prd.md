# 采发发会员工作台 V1 PRD

2026-11-09 · @sanyuan

## 1. 文档信息与范围

本 PRD 定义会员工作台 V1（11/20 上线）的前后台行为：服务商在工作台按项目看商城、询价单、订单和经营数据，从项目直接发起建商城、选品和询价。场景货盘在会员首页（即年货节版场景运营首页）展示；工作台只保留档期卡，为当前档期的热门货盘增加曝光。

| 项 | 内容 |
| --- | --- |
| 版本 | V1 · 年货节存量增长版，2026-11-20 上线 |
| 端 | 会员端 PC（工作台、首页会员面板）· 新运营管理后台 |
| 一句话价值 | 服务商按甲方项目看账，从项目发起询价、选品和建商城 |
| 解决什么 | 增长（存量年货节 GMV）+ 底层能力（项目信息积累） |
| 关联文档 | 买家侧产品形态与版本规划 v1.0；会员端 V1.0 年货节版场景运营 Spec（11/05）；会员工作台调整方案；会员工作台 V1 产品说明书 |
| 对应任务 | V1-3、V1-4、V1-5、V1-10（V1-9.2 货盘入口放会员首页；工作台只保留档期卡引流）；询价表单变更来自 V1-2.4 |

**本期做**

- 项目：存量商城自动生成、项目列表、新增、详情、编辑、合并、从项目发起动作。
- 入口：年货节档期卡（曝光当前档期热门货盘，点击跳会员首页）、项目、我的询价单；首页常用功能可选项新增。场景货盘本身在会员首页，见场景运营 Spec。
- 询价表单新增必填：选商城、客户类型、预算。
- 新手指引、项目数据权限与脱敏、埋点。
- 名片、企微营销下线（P2）。

**本期不做（去向）**

| 事项 | 去向 |
| --- | --- |
| 栏目完整重组、订单合并为全货源入口 | V3 |
| 报价单 | 后续版本 |
| 项目 AI 选品开通 | V2 |
| 项目供货价、项目信息回传商家 | V4 |
| 项目月报、新建看板 | 不做；经营数据复用现有口径 |

## 2. 角色与权限

| 角色 | 端 | 本期能做的事 |
| --- | --- | --- |
| 服务商管理员 | 会员端 | 看本企业全部项目；新增、编辑、合并项目；取用货盘、发起询价 |
| 服务商业务员（子账号） | 会员端 | 看自己有商城权限的项目；编辑和合并项目需「项目管理」权限点；取用货盘、发起询价 |
| 商品运营 | 运营后台 | 处理询价单；看项目汇总 |
| 指定角色（如运营负责人） | 运营后台 | 看单个项目明细（脱敏、留痕） |

**新增权限点**

| 权限点 | 控制内容 | 无权限时 |
| --- | --- | --- |
| 项目管理 | 新增、编辑、合并项目 | 按钮隐藏，项目只读 |

- 项目可见范围跟随商城权限：子账号能看到的项目 = 其有权限的商城所属项目 + 自己创建的项目。
- 老账号迁移：管理员默认拥有「项目管理」；子账号按原「商城管理」权限映射。
- 货盘上架、代发、加购沿用场景首页 Spec 的权限点；询价不设权限点。

## 4. 项目

项目是服务商为一个甲方做的一笔生意，商城、询价单、订单都挂在项目下。V1 不做独立报备入口：存量商城自动生成项目，询价时顺手补信息。

### 4.1 数据模型

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 项目 ID | 系统生成 | — |
| 项目名称 | 文本 ≤ 30 字 | 必填；自动生成时 = 商城名称 |
| 项目类型 | 单选：采购 / 集采 | 默认采购 |
| 归属方 | 系统带出 | 采购项目 → 服务商；集采项目 → 商家；不可编辑 |
| 客户类型 | 单选 | 可为空；枚举见 4.2 |
| 预算类型 | 单选 | 可为空；枚举见 4.2 |
| 预算金额 | 金额（元），整数 | 可为空 |
| 兑换价格带 | 系统计算 | 按项目下商城实际订单计算，不可填；无订单显示「暂无」 |
| 信息来源 | 系统 | 系统生成 / 服务商填写 / 询价带入 / 运营补录，按字段记录 |
| 创建时间 | 系统 | 为后续项目供货价资格留依据；合并后取最早的一个 |

关系：一个项目可有多个商城；一个商城只属于一个项目。订单通过商城归到项目；询价单通过所选商城归到项目，选「还没建商城」时为未关联。

### 4.2 枚举

| 字段 | 选项 |
| --- | --- |
| 客户类型 | 政府机关 / 事业单位 / 央企国企 / 民营企业 / 外资企业 / 其他 |
| 预算类型 | 工会福利 / 行政福利 / 营销礼品 / 办公采购 / 其他 |

### 4.3 存量商城自动生成项目

- 上线时一次性为所有存量商城生成项目：一个商城一个项目，名称 = 商城名称，项目类型 = 采购，创建时间 = 商城创建时间。上线后新建的商城若没有从项目发起，同样自动生成。
- 客户类型按商城名称关键词推断（如含「局」「厅」「委」→ 政府机关；「医院」「学校」→ 事业单位）；命中多个或无法判断时留空。关键词词典由产品提供初版，存配置表，不写死在代码里。
- 推断结果的信息来源记为「系统生成」，项目详情中标「系统推断，可修改」。
- 兑换价格带按历史订单计算，每日 T+1 更新。

### 4.4 项目列表

| 列 | 说明 |
| --- | --- |
| 项目名称 | 点击进详情；下方小字显示项目类型、客户类型（空则显示「待补全」） |
| 商城数 | 项目下商城数 |
| 询价中 | 待跟进 + 跟进中的询价单数 |
| 交易额 | 项目下全部商城订单金额，复用现有经营概览口径 |
| 利润 | 复用现有经营概览口径 |
| 最近成交 | 最近一笔订单时间 |
| 操作 | 详情 · 发起询价 · 更多（建商城、去选品、编辑） |

- 筛选：项目名称 / 商城名称搜索、项目类型、客户类型（含「未填」）、信息待补全（是 / 否）。
- 排序：默认按最近成交时间倒序；交易额、利润可点表头排序。每页 20 条。
- 顶部提示条（有则显示）：「N 个项目还缺客户类型或预算，补全后可按客户类型看经营数据」·「M 个询价单未关联商城」，各带跳转。
- 批量勾选 ≥ 2 个项目后，列表上方出现「合并项目」。
- 右上角「新增项目」。无「项目管理」权限时，勾选框、新增和编辑均隐藏。
- 空状态：「还没有项目。建一个商城，项目会自动生成」+「去建商城」「新增项目」。

### 4.5 新增 / 编辑项目

- 弹窗字段：项目名称（必填）、项目类型、客户类型、预算类型、预算金额；归属方随项目类型只读显示。
- 同一企业下项目名称不可重复，重复时提示「已有同名项目，可直接合并」。
- 弹窗底部固定提示：「项目信息用于经营管理数据统计，本版不提供给任何第三方。已完善信息的项目，其集采询价优先跟进。」不写保护承诺。
- 保存后 toast「已保存」，信息来源记为「服务商填写」。

### 4.6 项目详情

| 区块 | 内容与规则 |
| --- | --- |
| 顶部 | 项目名称、类型标签、创建时间；右侧按钮：发起询价（主）、去选品、建商城、编辑 |
| 项目信息 | 客户类型、预算类型、预算金额、归属方、兑换价格带；空字段显示「去补全」；系统推断的字段带「系统推断」标记 |
| 经营数据 | 订单数、交易额、利润、兑换价格带；时间范围：近 30 天 / 本年 / 全部，默认全部；口径同经营概览 |
| 商城 Tab | 商城名称、状态、商品数、交易额；点击跳商城运营中心；「移到其他项目」（需项目管理权限） |
| 询价单 Tab | 询价单号、商品数、询价类型、状态、提交时间；点击打开询价单详情抽屉 |
| 订单 Tab | 订单号、商城、金额、状态、下单时间；最近 50 条，「查看全部」跳现有订单管理并带商城筛选 |

### 4.7 从项目发起动作

| 动作 | 跳转 | 自动带上 |
| --- | --- | --- |
| 发起询价 | 询价弹窗（未选商品时可在弹窗内搜索添加） | 商城（项目只有一个商城时自动选中）、客户类型、预算，可改 |
| 去选品 | 会员首页场景商品池，顶部显示「正在为「xx 项目」选品 ✕」 | 上架时默认勾选本项目的商城 |
| 建商城 | 现有建商城流程 | 新商城挂到本项目，不再自动生成新项目 |

### 4.8 合并项目

1. 在项目列表勾选 2–10 个项目，点「合并项目」。
2. 弹窗列出所选项目（名称、商城数、交易额、客户类型），单选「保留哪个项目的名称和信息」，默认选交易额最大的。
3. 确认文案：「合并后，N 个商城、M 个询价单和全部订单将归到「xx」，其他项目将被删除。」
4. 合并后：未保留项目的商城、询价单归入保留项目；保留项目的空字段用其他项目的值补上；创建时间取最早的；经营数据和价格带重新计算。
5. 合并记录写入操作日志（操作人、时间、被合并项目）。是否支持撤销见待确认。

异常：所选项目项目类型不同时，弹窗提示「项目类型不一致，合并后以保留项目为准」；合并过程中有人编辑同一项目时，提示「项目已变化，请刷新后重试」。

## 5. 档期卡与场景货盘

场景货盘和场景商品池在会员首页（即年货节版场景运营首页，规则以场景运营 Spec 为准）。工作台不放货盘列表，只保留档期卡，用来给当前档期的热门货盘增加曝光。

### 5.1 档期卡

| 项 | 规则 |
| --- | --- |
| 位置 | 工作台首页顶部通栏 |
| 内容 | 档期名 + 距节日 N 天 + 一句运营文案；当前档期热门货盘最多 3 个，每个显示货盘名、商品数、缩略图；右侧「去选货」 |
| 热门货盘来源 | 场景配置的「时令档期」运营位，运营指定货盘及顺序；未指定时按货盘排序值取前 3 个 |
| 跳转 | 点货盘 → 会员首页对应二级场景；点「去选货」→ 会员首页当前档期一级场景 |
| 可见 | 只展示对会员可见且生效中的场景和货盘；没有时不显示通栏 |
| 收起 | 可收起为一行提示，按账号记住；换档期后重新展开 |

### 5.2 工作台与会员首页的衔接

- 项目「去选品」：跳会员首页场景商品池并带项目参数；顶部显示「正在为「xx 项目」选品 ✕」，上架弹窗默认勾选该项目的商城，询价弹窗预填该项目的商城、客户类型、预算。上下文在首页内切换场景时保持，点 ✕ 退出。
- 首页产生的上架任务和询价单归到对应商城的项目，在工作台项目详情里可见。
- 版本规划 V1-9.2（会员工作台增加货盘入口）按此调整：货盘入口在会员首页，不在工作台。

## 6. 询价

### 6.1 询价弹窗变更

在场景首页 Spec「询价」表单基础上，新增顶部「项目信息」区，三项必填：

| 字段 | 规则 |
| --- | --- |
| 用在哪个商城 | 必填；下拉搜索本企业有权限的商城，每项显示「商城名 · 所属项目」；末项「还没建商城」 |
| 客户类型 | 必填；选商城后用其项目的值预填，可改 |
| 预算 | 必填；预算类型 + 预算金额（元），同样预填可改 |

- 提交后：询价单关联所选商城的项目；若项目的客户类型或预算为空，用本次填写值补上（信息来源 = 询价带入）；已有值且不同时，不覆盖项目，只记在询价单上。
- 选「还没建商城」：询价单状态为未关联；以后建商城时弹提示「你有 N 个询价单未关联商城，要挂到这个商城吗」。
- 场景首页、货盘、搜索结果、商品详情、项目详情处发起的询价都用同一弹窗。
- 场景首页 Spec 的询价表单需同步补上这三项。

### 6.2 我的询价单

| 列 | 说明 |
| --- | --- |
| 询价单号 | 点击打开详情抽屉 |
| 商品 | 首个商品名 +「等 N 件」 |
| 询价类型 | 大批量采购 / 定制需求 / 价格咨询 / 货期咨询 |
| 商城 / 项目 | 未关联显示「未关联」+「去关联」 |
| 提交人、提交时间 | — |
| 状态 | 待跟进 / 跟进中 / 已关闭（悬停显示关闭原因） |

- 筛选：状态、询价类型、项目、是否关联、提交时间。子账号只看自己提交的和自己有权限商城下的。
- 详情抽屉：全部表单字段、商品明细、状态变更记录、运营对外的跟进说明（内部跟进记录不展示）。会员端只读；未关联的可在抽屉里选择商城。
- 本版不生成报价单。

## 7. 首页会员面板与栏目下线

### 7.1 首页会员面板

- 「企业工作台」常用功能由用户自己选择。可选列表新增「我的项目」「询价单」，带 NEW 标记；不改用户已选的功能。
- 待办 2×2 中「询价单（待处理）」= 状态为待跟进或跟进中的询价单数，点击进我的询价单并带状态筛选。

### 7.2 名片、企微营销下线（P2）

- 范围：「营销」下「名片营销」「企微营销」两个分组；「卡券营销」保留。「客户」下的企微好友、企微客户群不动。
- 前提：技术拉近 90 天这两组页面的访问量和访问企业数，确认无人使用后再下线。
- 方式：只从菜单隐藏，数据保留；直接访问旧路由时显示「该功能已下线，如需使用请联系客户经理」。

## 8. 新手指引（P0）

新手指引和功能同版上线；指引组件做成通用能力，后续版本新增或重构入口时复用。

### 8.1 分步引导

每个账号上线后首次进入工作台触发，蒙层高亮目标入口，气泡含标题、一句说明、「下一步」「跳过」和步骤数。

| 步 | 高亮 | 标题 | 说明 |
| --- | --- | --- | --- |
| 1 | 年货节档期卡 | 年货节热门货盘 | 运营推荐的当季热门货盘，点进去就能选货上架 |
| 2 | 「项目」菜单 | 按甲方看生意 | 你的商城已按项目整理好，商城、询价、订单和账都在一页 |
| 3 | 「我的询价单」 | 询价进度在这里 | 提交的询价单和跟进状态都能在这里看到 |
| 4 | 右上角「新功能指引」 | 随时重看 | 忘了入口在哪，点这里再看一遍 |

- 最后一步按钮为「知道了」。跳过或完成后不再自动弹出。
- 工作台右上角增加「新功能指引」，点击重新播放。
- 某一步的目标不可见（如无可见场景、无权限）时跳过该步，步骤数重新计算。

### 8.2 其他指引

| 形式 | 触发 | 内容 | 关闭 |
| --- | --- | --- | --- |
| NEW 角标 | 入口未被点击过 | 项目、我的询价单、常用功能可选项 | 点击一次消失；上线 30 天后统一去掉 |
| 首页气泡 | 上线后首次进入首页 | 指向常用功能「编辑」：「新增「我的项目」「询价单」，可加入常用」 | 关闭或点击后不再出现 |
| 空状态 | 列表为空 | 见 4.4、6.2；都带跳转按钮 | — |
| 老页面提示 | 进入「我的商城」「经营概览」 | 顶部轻提示：「现在也可以在「项目」里按甲方查看」+ 去看看 | 可关闭，关闭后不再出现 |

- 指引状态按账号记录（服务端），换浏览器不重复弹；子账号各自独立。
- 老菜单含 iframe 页面，指引只高亮主应用内的入口，不覆盖 iframe 内容。

## 9. 运营后台：权限、脱敏、留痕

项目视图上线后，运营后台就能看到项目明细，权限和脱敏必须同版上线。新功能放在新运营管理后台，菜单：会员运营 → 项目数据。

| 规则 | 优先级 |
| --- | --- |
| 不存终端企业联系人和联系方式字段；平台消息和通知只发给服务商账号 | P0 |
| 项目数据页默认只看汇总：按客户类型、预算类型、项目类型统计项目数与 GMV，及带客户类型和预算的项目 GMV 覆盖率 | P0 |
| 查看单个项目明细需「项目明细查看」角色权限 | P0 |
| 客户名称（即项目 / 商城名称中的甲方名）加密存储；运营后台显示脱敏名称，如「某央企国企·北京」；含客户名称的明细不支持导出 | P0 |
| 查看、导出项目明细记日志（谁、何时、哪个项目），管理员可查 | P1 |
| 涉及项目和客户信息的页面加明水印（查看人账号 + 时间），导出的汇总文件同样带水印 | P1 |
| 待补录项目清单：列出有交易、信息不全的项目，按交易额排序；运营可代补，来源记为「运营补录」 | P1 |

询价单后台列表沿用场景首页 Spec，新增「项目」「客户类型」「预算」三列和「是否关联」筛选，项目名同样脱敏显示。

### 10.2 上线

- 上线前：存量商城生成项目的脚本在预发环境跑一遍，核对项目数 = 商城数、项目交易额合计 = 经营概览总额；抽 50 个商城人工看客户类型推断。
- 灰度：先开 3–5 家友好服务商，运行 2 天无问题后 11/20 全量。
- 回滚：新入口可按开关隐藏；项目数据不影响老菜单，关入口即可回退。

### 10.3 验收标准

- [ ] 存量商城 100% 生成项目，项目交易额合计与经营概览一致
- [ ] 无法推断的客户类型为空，并在列表显示「待补全」
- [ ] 合并后商城、询价单、订单全部归到保留项目，经营数据重新汇总，创建时间取最早
- [ ] 询价不填商城、客户类型、预算时无法提交；从项目发起时三项预填
- [ ] 无「项目管理」权限的子账号看不到新增、编辑、合并；只看到有权限商城的项目
- [ ] 新手指引每个账号只自动弹一次，可跳过、可重看；换浏览器不重弹
- [ ] 会员端任何页面不出现接口价；运营后台无权限角色看不到项目明细，客户名称脱敏

**版本门槛**（目标值待与运营商定）：存量交易 GMV、货盘上架商城数、自助询价数、带客户类型和预算的项目 GMV 覆盖率、档期卡货盘点击后的上架与询价数、入口发现率（上线 2 周内点过项目或我的询价单的活跃服务商占比）。
