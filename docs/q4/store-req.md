# 会员端「店铺」模块需求说明（我的店铺 / 专供店铺）

2026-11-25

会员端新增一级菜单「店铺」，下面两个页面：**我的店铺**（会员自营店，放会员自己的商品）和**专供店铺**（供应商为本会员开的专供店）。商品管理复用卖家侧，专供商品要经会员审核通过才能进资源广场。本文是这个模块的需求清单和需求说明，页面交互以画布「店铺 › 我的店铺」「店铺 › 专供店铺」两张画板为准。

## 一、背景与目标

现状：会员的自有商品放在「商品库 / 商品发布 / 商品导入」，自有供应商靠会员给对方开供应商账号来管。一家供应商常被十几家会员各开一个账号，商务要逐个登录上品、对单；会员和供应商之间的报价、改价、发货仍在微信群里。

方向（11/07、11/11、11/12 会议与 Q4 规划 V3）：

- 一切供给都以店铺出现，底层用卖家侧同一套店铺和商品模型，买家侧不另建。
- 会员的自有商品 → **会员自营店**：自己给自己供货，不收佣、不需要认证。
- 会员的自有供应商 → **商家专供店**：会员发邀请，供应商接受后开专供店（需认证），只对这个会员可见；会员像逛商城一样进店选货。
- 专供店先做**工具 + 信息流**，不碰资金，不急着让双方和平台成交。

本模块目标：

1. 会员在一个入口管好自己的商品和所有专供店；
2. 供应商给的价格和图片先经会员把关，再进入选品；
3. 会员能看到每个专供商品铺到了哪些商城、出了多少单。

## 二、范围

| | 内容 |
| --- | --- |
| 本期做 | 店铺一级菜单与入口迁移；我的店铺（店铺信息、商品管理、四种添加方式、上架到商城）；专供店铺（店铺列表、店铺详情、供货商品审核、已铺商城与订单统计）；资源广场按来源区分平台 / 自营 / 专供；工作台待办「专供商品待审核」 |
| 本期只留入口 | 邀请供应商开店（V3.2，邀请链接机制待卖家侧补充）；自营商品供给其他会员（V3.4，一键导入专供店） |
| 本期不做 | 专供订单推送与发货回传、对账与付款凭证、服务费账户（V3.3）；购物车和订单按店铺拆单（V3.5）；店铺评分（V4.2）；主店铺 + 子店铺的供货规则（V4.3）；店铺装修 |

## 三、概念与角色

| 概念 | 说明 |
| --- | --- |
| 会员自营店 | 会员自己的店，放自有商品，只供自己的商城和代发使用。成为会员即开通，店铺名默认取组织名 |
| 商家专供店 | 供应商在卖家侧为本会员开的店。会员只能看到对自己开放的商品和价格，看不到它给其他会员的 |
| 专供代发价 | 供应商在卖家侧「客户关系 › 供货配置」里给本会员配的一件代发价（含税），有版本（V1、V2…） |
| 当前有效价 | 会员最近一次审核通过的专供代发价版本。新版本审核通过前一直按它供货（对应卖家侧「新版本确认前，仍使用当前有效供价」） |
| 资源广场 | 会员选品的地方。来源分平台、自营、专供三类；专供商品只对本会员可见 |

| 角色 | 在本模块做什么 |
| --- | --- |
| 会员（服务商） | 管理自营店商品；审核专供商品；把商品上架到商城或代发下单；看铺货和订单统计 |
| 供应商（卖家侧） | 为会员开专供店、配专供代发价和商品；看到会员的审核结果，被驳回后修改重提 |
| 平台运营 | 处理存量供应商账号迁移；不参与专供商品审核 |

## 四、业务流程

1. **建立合作**：供应商接受会员邀请并完成企业认证后，专供店对该会员可见，状态「合作中」。（邀请本期只留入口；存量供应商走迁移，见 E16。）
2. **供货配置**：供应商在卖家侧选择给本会员供货的商品，配置专供代发价，提交后卖家侧显示「待对方确认」。
3. **会员审核**：会员在「专供店铺 › 店铺详情」看到待审核商品，重点检查价格和主图，通过或驳回。
4. **进入资源广场**：审核通过的商品进入会员资源广场（来源「专供 · 店铺名」），会员才能选它上架商城或代发下单。
5. **改价**：供应商提交新报价版本 → 会员再审。通过前仍按当前有效价供货，通过后新价立即生效。
6. **统计**：会员在店铺详情的「数据统计」里看每个商品铺到了哪些商城、出了多少单。

我的店铺不经过审核：会员上架的商品直接进入资源广场的「自营」来源。

## 六、需求说明

### 1. 店铺入口（D1–D4）

- 一级菜单「店铺」位于「商品」之后，二级菜单两项：我的店铺、专供店铺。
- 原菜单迁移：

| 原入口 | 去向 | 处理 |
| --- | --- | --- |
| 商品库 | 我的店铺 › 商品管理 | 旧链接 302 跳转，首次进入顶部提示「商品库已搬到店铺 › 我的店铺」 |
| 商品发布 / 商品导入 | 我的店铺 › 添加商品 | 同上 |
| 供应商管理 | 专供店铺 | 存量账号迁移完成前保留只读入口，见 E16 |

- 工作台分步指引的「店铺」一步说明：自有商品在我的店铺，供应商为你开的店在专供店铺，新商品要审核后才能选。

### 2. 我的店铺（M1–M11）

**页面结构**：店铺信息卡 → 商品管理（页签 + 搜索 + 批量操作 + 列表）→「供给其他会员」预留区。

**商品列表字段**：

| 字段 | 口径 | 来源 |
| --- | --- | --- |
| 商品 | 主图、名称、规格数、货号 | 商品库 |
| 成本价 | 会员录入的采购成本（含税），仅自己可见 | 商品库 · 成本价 |
| 市场价 | 会员填写的市场价 | 商品库 · 市场价 |
| 建议售价 | 上架到商城时默认带出的售价 | 商品库 · 建议售价 |
| 库存 / 交期 | 现货库存；无现货时显示交期（天） | 商品库 |
| 已铺商城 | 已上架该商品的本会员商城 | 业务库 · 商城商品 |
| 近 30 天订单 | 近 30 天含该商品的商城订单 + 代发订单数 | 业务库 · 商城订单、代发订单 |

**添加商品**（复用卖家侧「新建商品」，会员侧只换入口）：

| 方式 | 说明 |
| --- | --- |
| 找同款发品 | 上传图片或输入名称，从平台商品库找同款，自动带出名称、类目、品牌、规格、图片 |
| 采集发品 | 粘贴电商商品链接采集信息 |
| 表格发品 | 下载模板批量导入，导入后给出成功数和失败明细 |
| 手工录入 | 分步表单：图片 / 视频 → 基础信息 → 规格与价格 → 履约与售后 → 详情 |

必填项：主图、商品名称、三级分类、品牌、规格、成本价、市场价、建议售价、库存或交期、交付方式。缺必填项只能保存为草稿。

**规则**：

- 自营店商品上架即进入资源广场「自营」来源，不需要审核。
- 商品下架：资源广场同步移除；已上架到商城的同步下架，并在商品管理里提示受影响的商城数。
- 建议售价只是默认值，各商城可单独定价（一个商城 = 一个项目，售价按商城定）。
- 成本价只用于会员自己看毛利，不对外展示。

### 3. 专供店铺 · 店铺列表与详情（E1–E5、E14–E16）

**列表页**：顶部汇总数字（E1）+ 店铺卡片网格（E2）。卡片点击进入店铺详情；待开店的店铺可以点开，但商品列表为空并提示「供应商完成认证后开始供货」。

**店铺详情**：返回列表 → 店铺基本信息 → 页签「供货商品」「数据统计」。

**供货商品列表字段**：

| 字段 | 口径 | 来源 |
| --- | --- | --- |
| 商品 | 主图、名称、规格、类目 | 卖家侧 · 商品库 |
| 专供代发价（含税） | 当前有效价；改价时并列新报价和涨跌幅 | 卖家侧 · 客户供货配置 |
| 市场价 | 供应商填写的市场价 | 卖家侧 · 商品库 |
| 审核状态 | 待审核（新品 / 改价）/ 已通过 / 已驳回 | 买家侧 · 审核记录 |
| 提醒 | 高于平台同款、主图待确认、改价影响毛利 | 系统预检 |
| 已铺商城 | 已上架该商品的本会员商城 | 业务库 · 商城商品 |
| 近 30 天订单 | 近 30 天含该商品的商城订单 + 代发订单数 | 业务库 · 商城订单、代发订单 |

### 4. 专供商品审核（E7–E12）

审核在右侧抽屉中完成，内容从上到下：

1. **主图**：大图 + 缩略图，系统预检四项，未通过项标橙：
   - 尺寸不小于 800 × 800；
   - 无水印、二维码、联系方式；
   - 图上文字与供价一致，无促销误导；
   - 与商品名称、规格一致。
2. **价格**：

| 项 | 说明 |
| --- | --- |
| 新报价 / 专供代发价 | 本次待审核的价格 |
| 当前有效价 | 改价时显示，并显示涨跌幅；新品不显示 |
| 市场价 | 供应商填写 |
| 平台同款参考价 | 通过卖家侧同品关联匹配猫超、京东同款的最低价；无同款时显示「暂无同款」 |
| 毛利空间 | （市场价 − 新报价）÷ 市场价 |

3. **售后与发票**：供应商填写的售后政策和开票说明，只读。

**提醒规则**（只提醒，不拦截）：

- 新报价高于平台同款参考价：提示差额。
- 改价涨价，且该商品已上架商城：提示「已上架 N 个商城，按当前售价毛利将从 x% 降到 y%」。
- 主图预检有未通过项：通过按钮旁提示「主图有 N 项待确认」，需勾选「已确认主图」才能通过。

**操作**：

| 操作 | 结果 |
| --- | --- |
| 审核通过 · 进入资源广场 | 新品：进入资源广场「专供 · 店铺名」。改价：新价立即成为当前有效价，已上架商城的成本同步更新，售价不变。卖家侧显示「客户供价已确认」 |
| 驳回 | 必选原因，可补充说明；回传卖家侧。新品不进入资源广场；改价继续按当前有效价供货。供应商修改后重新提交，重新进入待审核 |

**待审核提醒**：工作台待办「专供商品待审核 N」，点击直达对应店铺并筛到待审核；供应商新提交时发站内消息。

### 5. 数据统计（E13）

- 店铺维度（列表卡片上）：已通过商品数、已铺商城数、近 30 天订单。
- 商品维度：每个已通过商品的已铺商城数、近 30 天订单、近 30 天销售额，按订单数倒序。
- 商城维度：本店商品在每个商城产生的订单数和占比。
- V1 只做基于现有数据的统计，不做预测、不给经营建议。

### 6. 资源广场联动（R1–R2）

- 资源广场增加来源筛选：全部 / 平台 / 自营 / 专供（可再选店铺）；商品卡左上角标来源。
- 专供商品只对本会员可见，显示当前有效专供代发价。
- 会员选专供商品上架商城或代发下单时，成本价取当前有效专供代发价；经营分析中专供商品毛利 = 商城售价 − 专供代发价。

## 七、状态定义

### 1. 专供商品审核状态

| 状态 | 进入条件 | 是否在资源广场 | 供货价 |
| --- | --- | --- | --- |
| 待审核 · 新品 | 供应商首次给本会员配置该商品并提交 | 否 | — |
| 待审核 · 改价 | 已通过的商品提交了新报价版本 | 是 | 当前有效价 |
| 已通过 | 会员审核通过 | 是 | 本次通过的价格 |
| 已驳回 · 新品 | 会员驳回新品 | 否 | — |
| 已驳回 · 改价 | 会员驳回改价 | 是 | 当前有效价不变 |
| 已停供 | 供应商停止供货或合作终止 | 否 | — |

### 2. 专供店铺合作状态

| 状态 | 卖家侧条件 | 会员侧表现 |
| --- | --- | --- |
| 待开店 | 供应商已接受邀请或已迁移，未完成企业认证 | 列表显示，商品为空，提示等待认证 |
| 合作中 | 认证通过、专供店已开 | 正常显示和审核 |
| 已终止 | 任一方终止合作 | 置底灰显，商品从资源广场移除，历史数据保留 |

## 八、数据口径

| 指标 | 口径 | 来源 |
| --- | --- | --- |
| 供货商品 | 该店给本会员配置过的商品数（不含已停供） | 卖家侧 · 客户供货配置 |
| 已通过 | 当前在资源广场里的商品数：已通过、待审核 · 改价、已驳回 · 改价 | 买家侧 · 审核记录 |
| 待审核 | 待审核 · 新品 + 待审核 · 改价 | 买家侧 · 审核记录 |
| 已铺商城 | 上架过该店任一商品、且当前仍在架的本会员商城数 | 业务库 · 商城商品 |
| 近 30 天订单 | 近 30 天含该商品的商城订单 + 代发订单；一单多商品按商品分别计入 | 业务库 · 商城订单、代发订单 |
| 近 30 天销售额 | 商城售价 × 数量，扣除退款；代发订单按代发价 | 业务库 · 订单明细 |
| 毛利 | 商城售价 − 会员成本（自营取成本价，专供取当前有效专供代发价，平台取会员价） | 业务库 + 商品库 |

## 十、待确认事项

1. ☐ 卖家侧是否新增「客户已驳回」状态和驳回原因（卖家 PRD 目前没有）。
2. ☐ 审核时效：供应商提交后多少天未审核要提醒或自动处理；是否支持批量审核。
3. ☐ 合作终止后，已上架到商城的专供商品是立即下架还是卖完下架。
4. ☐ 存量供应商账号的迁移节奏，「供应商管理」只读入口保留多久。
5. ☐ 专供店铺对哪些权益等级可见（目前原型只给最高权益；会员开自营店不设门槛）。
6. ☐ 阿里权益（自有猫超、优品）商品是否归入自营店，以及在自营店里能否编辑。
7. ☐ 自营店是否收费、是否收订单服务费（V3.4 评审点）。
8. ☐ 自营商品的采购成本录入方式：手填，还是从专供店订单带出（V3.4 评审点）。
