### 1.2 背景与目标

- 现有消费商城新旧两套前端并存、不同货源商品展示不一致、搜索不准，员工兑换时体验差，甲方会向服务商追责。
- 目标：一套前端、一套商品模板、一套价格口径；员工找得到、看得懂、按余额顺利兑换；全流程有埋点。

### 1.3 用户与终端

- 用户：员工（兑换人）。服务商和平台运营只在后台配套中出现。
- 终端：H5（手机浏览器 / 微信内打开）。PC 端是否同步待确认。
- 商城类型：现金商城为主；积分商城只差价格展示（积分 + 金额），其余一致。

## 二、全局规则与通用组件

以下规则对所有页面生效，各页面章节不再重复。

### 2.1 业务规则

| # | 规则 | 内容 |
| --- | --- | --- |
| R1 | 价格 | C 端只有三类价格：商品价（销售价、市场价、积分价、阶梯价）、优惠、结算金额。市场价仅在站点开启且高于销售价时以划线展示，全局叫「市场价」。接口价、会员价、分销价、利润率、平均到手价、券前价、价格力标签不下发到 C 端接口 |
| R2 | 货源标签 | 天猫超市 / 天猫优品用官方角标；京东渠道商品统一称「电商精选商品」，角标显示「电商精选」；平台自有供应商商品显示「精选」；C 端不出现「京东」字样；卡券显示「电子卡券」；入驻商家不显示（本期不展示店铺名 / 商家名）。站点关闭货源标签时全部不显示。购物车分组名、包裹标题与标签叫法一致 |
| R3 | 商品标签 | 营销标签每商品最多 3 个（商品池规则反向打标）；热销 = 平台销量前 5000；24 小时发货 = 电商仓。商品卡最多 2 个，顺序 营销标签 > 热销 > 24 小时发货；详情页全部显示。服务项不进标签；「供货稳定」只内部使用 |
| R4 | 发货时效 | 不写仓库名。电商仓（猫超仓、电商精选商品的京东物流仓，只用于内部判断）写「24 小时内发货」，商家仓写「N 天内发货」（N 取商家承诺），卡券写「电子发放，无需物流」 |
| R5 | 库存与可售 | 按收货地区判断：有货 / 库存紧张（< 50）/ 无货；地区不可售与无货都不可买。员工无地址时用商城默认三级地址判断，该地址不展示为「发货地」 |
| R6 | 余额与混合付 | 员工用商城余额兑换。合计 ≤ 余额：全额抵扣；超出且站点允许混合付：超出部分员工自付；超出且不允许：不可结算，提示「还差 ¥x」 |
| R7 | 销量 | 低于 100 不显示；电商精选商品（京东渠道）销量等级展示规则待定 |
| R8 | 电商精选口碑 | 好评率 + 评价数一起显示；好评率低于 88% 只显示评价数；评价数按档显示（100+ / 1 万+）；点击打开京东评价组件。评价正文不展示 |
| R9 | 登录 | 浏览不要求登录（以站点「下单是否需登录」配置为准）；加购、兑换、进入购物车 / 个人中心前未登录则先登录，登录后回到原页面并继续原操作 |
| R10 | 图片 | 商品图地址统一 https；加载失败显示商城统一缺省图 |
| R11 | 缺失字段 | 渠道字段取不到时整块隐藏，不显示空值、「暂无」或占位 |
| R12 | 样式 | 商品卡、详情、购物车、结算关键样式固定；站点只能配主题色、Logo、首页装修、个人中心装修和现有开关 |

按页面逐一检查过「数量多」和「文字长」两类情况，统一归到下表。各页详细方案里写「见 2.3」的地方按本表执行。

| --- | --- | --- | --- |

## 四、分类页

**入口**：底部 Tab「分类」、首页品类导航「全部分类」。**页面结构**：顶部搜索框 → 左侧一级类目 → 右侧（二级类目 → 三级类目（有则显示）→ 热门品牌 → 排序 / 筛选 → 商品列表）→ 底部 Tab。

| 功能点 | 操作 | 可观察结果与规则 | 异常与边界 |
| --- | --- | --- | --- |
| 搜索框 | 点击 | 进入搜索前页 | — |
| 一级类目 | 点击 / 上下滑 | 选中项白底 + 主题色左侧指示条；右侧切换到该类目，滚动回顶部；类目多时左栏独立滚动 | 类目下无已上架商品时不显示该类目；类目来自站点分类配置 |
| 二级类目 | 点击 | 右侧顶部横向标签，按个数切换：≤ 4 个一行排开；5–8 个横向滑动，右侧渐隐提示可滑；> 8 个横向滑动 + 最右固定「全部 ▾」，点击向下展开类目面板（盖在商品列表上，3 列网格显示全部二级类目，有图标显示图标），点类目、「收起 ▴」或遮罩收起。点击筛出该二级类目商品，选中项自动滚到可见位置。有三级类目时，在下方再显示一行三级文字标签（首项「全部」，同样的滑动 / 展开规则） | 有图标显示图标 + 文字，无图标只显示文字，不留空白；类目名标签内最多 6 字、面板内最多 2 行，超出省略；只有 1 个二级类目时不显示标签栏 |
| 热门品牌 | 左右滑 / 点击 | 类目标签下方一行「热门品牌」：品牌 Logo + 名称（无 Logo 显示品牌名首字），最多 10 个横向滑动，末尾「更多」打开品牌面板（A–Z 索引）。点品牌后商品列表筛为「当前类目 + 该品牌」，品牌高亮，可多选，再点取消。排序：服务商置顶品牌 → 该类目下本商城在售商品数与近 30 天销量综合 | 该类目品牌少于 3 个时不显示；切换类目时重算并清除已选品牌；品牌名最多 5 字，超出省略 |
| 排序 / 筛选 | 点击 | 列表上方「综合 ▾」切换排序（综合 / 销量 / 价格），「筛选」打开筛选抽屉（同第五章，分类组只含当前类目子类目） | 筛选条件在切换一级类目时清空 |
| 商品列表 | 上滑 / 点击 | 单列商品行（图、标题、标签、价格、加购）；服务商置顶商品在前；上滑加载；右上「综合 ▾」可切排序 | 空状态提示「该分类暂无商品」 |
| 返回保留 | 从详情返回 | 保留已选一级 / 二级类目和滚动位置 | — |

## 五、商品列表页

**入口**：首页装修模块（专题、品类导航）、分类页二级类目、详情页品牌入口（参数弹窗里的品牌）、购物车「找相似」。搜索结果页复用本页。**页面结构**：顶部导航（返回、标题、搜索图标）→ 排序栏 → 快捷筛选 → 商品列表 → 悬浮按钮（回到顶部、购物车）。

| 功能点 | 操作 | 可观察结果与规则 | 异常与边界 |
| --- | --- | --- | --- |
| 标题 | 进入页面 | 显示类目名 / 专题名 / 品牌名 | 超长省略 |
| 排序栏 | 点击 | 综合（默认）/ 销量 / 价格；价格第一次升序、再点降序，箭头跟随；切换后列表回到顶部并重新加载 | 综合 = 服务商置顶优先 → 销量；专题页综合按专题排序值 |
| 快捷筛选 | 点击标签 | 余额内可兑 / 有货 / 24 小时发货 / 热销，可多选，选中主题色描边 + 浅底；超出屏幕横向滑动 | 「余额内可兑」未登录时点击先登录 |
| 筛选抽屉 | 点「筛选」 | 从右侧滑出，宽 85%，内容可上下滚动、底部按钮固定。分组依次为：① 发货时效（单选：不限 / 24 小时发货 / 3 天内发货 / 7 天内发货）② 分类（当前结果里的二 / 三级类目，多选）③ 品牌（当前结果里的品牌，按商品数降序，多选）④ 价格区间（两个输入框 + 3 个推荐区间，推荐区间按当前结果的价格分布计算）⑤ 货源（天猫超市 / 电商精选 / 精选 / 电子卡券，多选；站点关闭货源标签时不显示）。分类和品牌先显示 9 个（3 列），超出显示「全部 ▾」展开；品牌超过 30 个时展开后显示搜索框和 A–Z 字母索引。每组标题右侧显示已选摘要（如「海天、李锦记」，超长省略）。底部「重置」「查看 N 件商品」，N 随选择实时更新；确定后关闭并刷新列表，「筛选」主题色高亮并带已选数量 | 点遮罩或右滑关闭且不应用未确定的修改；最低价 > 最高价时自动互换；选项只来自当前结果，不出现选了必然无结果的项；N 为 0 时按钮置灰显示「没有符合的商品」；从分类页进入时「分类」组只显示该类目下的子类目 |
| 已选条件条 | 应用筛选后 | 快捷筛选下方出现已选条件标签（如「品牌：海天 ×」「24 小时发货 ×」），点 × 单独移除并刷新；末尾「清空」；超出横向滑动 | 无筛选时不显示；与快捷筛选重复的条件只在快捷筛选里高亮，不重复显示 |
| 吸顶 | 向上滚动 | 排序栏 + 快捷筛选吸顶 | — |

**推荐规则**

1. 只在当前商城已上架、有货、员工收货地区可售的商品里选；名称、价格、类目、库存不全的不推荐。
2. 金额区间：未开混合付的商城，组合总价在余额的 90%–100%；允许混合付的商城在 90%–110%。
3. 「供货稳定」商品优先。
4. 规则推荐（不耗 token）：按员工余额 + 最近搜索或浏览的相似品。
5. 从 AI 推荐加购并兑换的订单，订单来源记为「AI 选品」。

## 十五、验收标准与待确认

### 15.1 验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| A1 | 详情统一 | 猫超、电商精选（含京东渠道）、入驻商家、卡券各类商品使用同一详情模板；只有 8.6 渠道差异表列出的字段不同 |
| A2 | 价格与商家信息 | C 端任何页面不出现价格力标签、采购成本、利润、商家名或店铺名 |
| A3 | 标签 | 每个商品最多 3 个标签；不出现「7 天无理由」标签；电商精选商品显示「电商精选」，自有供应商商品显示「精选」，全站不出现「京东」 |
| A4 | 阈值 | 销量 < 100 不显示销量；好评率 < 88% 不显示好评率 |
| A5 | 京东评价 | 点击评价入口在商城内打开京东评价组件，关闭后回到原位置；详情页不展示评价正文 |
| A6 | AI 选品 | 从搜索进入时全屏打开并带入搜索词；推荐商品均在本商城可售范围内；退出商城后重新进入无历史对话 |
| A7 | 余额 | 购物车三种余额状态显示正确；不允许混合付且超额时无法结算；实付 = 商品合计 + 运费 − 优惠 − 余额抵扣 |
| A8 | 提交安全 | 提交按钮防重复；价格变化、库存不足、地区不可售均有明确弹窗 |
| A9 | 履约文案 | 电商仓商品显示「24 小时内发货」，其他按渠道配置显示（如「3–7 天内发货」） |
| A10 | 埋点 | P0 事件 100% 覆盖且公共字段完整 |
| A11 | 属性展示 | 只有天猫超市 / 优品、电商精选显示属性行；40 项属性、属性名 15 字、属性值 200 字的商品在弹窗内按 8.3a 正常显示，不溢出、不挤压 |
| A12 | 内容多 / 长 | 二级类目 20 个、品牌 50 个、规格值 30 个、订单 10 件商品时按 2.3 展示，页面不错位 |
| A13 | 个人中心配置 | 后台关闭 / 改名 / 调序任一资产项或功能入口后，商城刷新即生效；1 / 3 / 6 个资产项三种布局显示正确 |
| A14 | 预计送达 | 天猫超市、电商精选订单在待发货 / 待收货状态显示预计送达日期，与渠道返回一致；取不到时按 12.2a 降级 |
