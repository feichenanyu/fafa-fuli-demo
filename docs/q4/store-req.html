会员端「店铺」模块需求说明（我的店铺 / 专供店铺）

最新需求说明最后更新 2026-11-26 12:20

2026-11-26 修订（二）

会员端新增一级菜单「店铺」，下面两个页面：我的店铺（会员自营店，放会员自己的商品）和专供店铺（和会员建立了专供关系的供应商店铺）。专供关系可以由会员输入手机号邀请供应商建立，也可以由供应商邀请会员建立；专供商品要经会员审核通过才能进资源广场，供应商改了商品信息要在有效期内确认。本文是这个模块的需求清单和需求说明，页面交互以画布「店铺 › 我的店铺」「店铺 › 专供店铺」「受邀会员账号」三张画板为准。

本次修订（11-26）

  1. 我的店铺去掉「采集发品」：会员自有商品没有采集场景，卖家侧也已删除该功能。
  2. 专供商品「改价」扩展为「信息变更」：供应商改商品信息时指定确认有效期，有效期内按原信息售卖；超期未确认自动下架，重新审核后才能再上架、铺货。
  3. 补齐会员侧「邀请供应商开专供店」操作：输入手机号发通知到卖家侧，已是卖家则卖家接受并报价后建立专供关系，不是则走卖家入驻流程。卖家侧的邀请机制（「合作邀请」的邀请链接、「合作申请」）已上线，会员侧对接它，不另建。入口：专供店铺页、邀请记录、店铺菜单「邀请供应商」。
  4. 对接「供应商邀请会员」（卖家侧已上线的邀请链接）：会员已存在则自动建立专供关系；不存在则只开会员账号（未认证、无权益），能登录查看，会员价不开放，创建功能锁定。

一、背景与目标

现状：会员的自有商品放在「商品库 / 商品发布 / 商品导入」，自有供应商靠会员给对方开供应商账号来管。一家供应商常被十几家会员各开一个账号，商务要逐个登录上品、对单；会员和供应商之间的报价、改价、发货仍在微信群里。

方向（11/07、11/11、11/12 会议与 Q4 规划 V3）：

  • 一切供给都以店铺出现，底层用卖家侧同一套店铺和商品模型，买家侧不另建。
  • 会员的自有商品 → 会员自营店：自己给自己供货，不收佣、不需要认证。
  • 会员的自有供应商 → 商家专供店：会员发邀请代替开账号，供应商接受后开专供店（需认证），只对这个会员可见；会员像逛商城一样进店选货。
  • 供应商也可以把自己的客户单位邀请上平台，带来新会员。
  • 专供店先做工具 + 信息流，不碰资金，不急着让双方和平台成交。

本模块目标：

  1. 会员在一个入口管好自己的商品和所有专供店；
  2. 会员和供应商用手机号就能互相邀请、建立专供关系；
  3. 供应商给的价格、图片和后续改动先经会员把关，再进入选品；
  4. 会员能看到每个专供商品铺到了哪些商城、出了多少单。

二、范围

内容
本期做 店铺一级菜单与入口迁移；我的店铺（店铺信息、商品管理、三种添加方式、上架到商城）；专供店铺（邀请供应商、邀请记录、店铺列表、店铺详情、新品和信息变更审核、确认有效期与超期下架、已铺商城与订单统计）；供应商邀请会员（自动建立关系、受邀会员账号）；资源广场按来源区分平台 / 自营 / 专供；工作台待办「专供商品待审核」

三、概念与角色

概念 说明
会员自营店 会员自己的店，放自有商品，只供自己的商城和代发使用。成为会员即开通，店铺名默认取组织名
商家专供店 供应商在卖家侧为本会员开的店。会员只能看到对自己开放的商品和价格，看不到它给其他会员的
专供关系 会员和供应商之间的供货关系。来源两种：会员邀请（我邀请）、供应商邀请
专供代发价 供应商在卖家侧「客户关系 › 供货配置」里给本会员配的一件代发价（含税），有版本（V1、V2…）
信息变更 已通过的专供商品被供应商改了价格、主图、标题、规格等，提交时指定确认有效期
当前有效信息 会员最近一次审核通过的商品信息（含价格）。有效期内一直按它售卖
受邀会员账号 供应商邀请的客户单位还不是会员时开的账号：未认证、无权益，只能浏览
资源广场 会员选品的地方。来源分平台、自营、专供三类；专供商品只对本会员可见
角色 在本模块做什么
会员（服务商） 管理自营店商品；邀请供应商；审核专供商品和信息变更；把商品上架到商城或代发下单；看铺货和订单统计
供应商（卖家侧） 确认会员的合作邀请或按邀请入驻；邀请自己的客户单位；配专供商品和价格；提交信息变更并指定有效期；看会员的审核结果
客户运营 给受邀会员账号做企业认证、开通会员权益；处理存量供应商账号迁移

四、业务流程

1. 会员邀请供应商

  1. 会员在「专供店铺」点「邀请供应商开店」，输入供应商负责人的手机号。
  2. 系统按手机号查卖家侧：
  3. 已是平台卖家：发短信，邀请进入卖家后台「客户关系 › 合作邀请 › 合作申请」（卖家侧已上线，卖家看到的状态是「待我报价」）。卖家接受并选好供货商品、填写代发价后建立专供关系；还没开专供店的先开店。
  4. 还不是平台卖家：发入驻短信，链接带邀请标识；卖家按入驻流程注册、企业认证、开专供店，再按上面的方式报价。
  5. 卖家的报价进入该店「待审核 · 新品」，截止时间取卖家填的报价截止时间，会员确认后商品进资源广场。
  6. 会员在「邀请记录 › 我发出的」里看进度：待卖家报价 / 入驻中 / 待我确认报价 / 已建立 / 已拒绝 / 已过期。

2. 供应商邀请会员

  1. 供应商在卖家侧「客户关系 › 合作邀请 › 邀请买家合作」选好供货商品、填写代发价和报价截止时间，生成邀请链接（通用或定向，7 天有效），发给客户单位。（卖家侧已上线）
  2. 客户单位打开链接：
  3. 已是平台会员：自动建立专供关系，不需要会员再确认；邀请里的报价进入该店「待审核 · 新品」；会员下次进入专供店铺时提示一次「新的专供关系」，邀请记录「供应商发来的」里有记录。
  4. 还不是平台会员：只开会员账号（未认证、无权益），同时建立专供关系。该账号可以登录会员系统查看，但会员价不开放，工作台里的创建功能不可用，提示联系客户运营开通更高级的会员权益。

3. 专供商品审核与信息变更

  1. 供应商在卖家侧选择给本会员供货的商品，配置专供代发价并提交。
  2. 会员审核新品，重点检查价格和主图，通过或驳回。通过后进入资源广场（来源「专供 · 店铺名」），会员才能选它上架商城或代发下单。
  3. 供应商修改已通过商品的信息（价格、主图、标题、规格等）时指定确认有效期，商品进入「待审核 · 信息变更」：
  4. 有效期内按原商品信息继续售卖；
  5. 会员确认后新信息立即生效；
  6. 超期未确认：商品自动下架，从资源广场和所有已上架的商城撤下，状态「已下架 · 超期」。会员重新审核通过后回到资源广场，需要再上架、铺货到商城（可一键上架到原商城）。
  7. 会员在店铺详情「数据统计」里看每个商品铺到了哪些商城、出了多少单。

我的店铺不经过审核：会员上架的商品直接进入资源广场的「自营」来源。

E13 专供店铺 数据统计 P0 V3.3 店铺详情「数据统计」页签：按商品看已铺商城、订单、销售额；按商城看订单数和占比；口径见第九节
E14 专供店铺 已铺商城查看 P0 V3.3 列表最多显示 2 个商城名，其余显示 +N，点开可看全部并跳转到对应商城的商品管理
E15 专供店铺 终止合作的处理 P0 V3.3 合作终止后该店商品从资源广场移除，已上架商城的商品按待确认第 3 条处理；历史订单和统计保留
E16 专供店铺 存量供应商账号迁移引导 P1 V3.2 有存量供应商账号的会员进入专供店铺时看到迁移提示和进度；迁移策略按待确认第 4 条执行
E17 专供店铺 信息变更的确认有效期 P0 V3.3 列表和审核抽屉显示截止日和剩余天数（≤ 3 天标橙）；有效期内资源广场和商城继续按原信息售卖
E18 专供店铺 超期自动下架 P0 V3.3 到期仍未确认：商品从资源广场和所有已上架商城撤下，状态「已下架 · 超期」；已下单的订单按下单时的信息履约；发站内消息通知会员
E19 专供店铺 超期后重新审核 P0 V3.3 已下架商品可「重新审核」；通过后回到资源广场，不自动恢复到原商城；审核抽屉提供「一键上架到原 N 个商城」，按商城原售价恢复
R1 资源广场 按来源区分商品 P0 V3.2 资源广场可按「平台 / 自营 / 专供」筛选，专供可再按店铺筛选；商品卡标来源；专供商品只对本会员可见
R2 资源广场 专供商品的价格与信息 P0 V3.3 资源广场、商城上架、经营分析里的成本价都取当前有效专供代发价；信息变更通过后已上架商城的售价不自动改，商品管理里提示毛利变化

原 E4「邀请供应商开店（预留）」已改为 I1–I4 正式做，编号不再使用。

  8. 与商品名称、规格一致。

十、待确认事项

  1. ☐ 卖家侧是否新增「客户已驳回」状态和驳回原因（卖家 PRD 目前没有）。
  2. ☐ 信息变更的确认有效期：卖家可设的范围（最短 / 最长几天）、默认值；驳回后是否延长有效期；是否支持批量审核。
  3. ☐ 合作终止后，已上架到商城的专供商品是立即下架还是卖完下架。
  4. ☐ 存量供应商账号的迁移节奏，「供应商管理」只读入口保留多久。
  5. ☐ 专供店铺对哪些权益等级可见（目前原型只给最高权益；会员开自营店不设门槛）。
  6. ☐ 阿里权益（自有猫超、优品）商品是否归入自营店，以及在自营店里能否编辑。
  7. ☐ 自营店是否收费、是否收订单服务费（V3.4 评审点）。
  8. ☐ 自营商品的采购成本录入方式：手填，还是从专供店订单带出（V3.4 评审点）。
  9. ☐ 邀请的有效期（原型按 14 天）；同一手机号重复邀请的处理；一个手机号对应多个卖家主体或多个会员组织时怎么选。
  10. ☐ 受邀会员账号能否看到邀请方给的专供代发价（原型按不展示）；是否计入会员数、是否收费；多久未开通权益要回收账号。
  11. ☐ 供应商邀请已存在的会员时，会员能否拒绝或解除这条自动建立的专供关系。
  12. ☐ 卖家侧 PRD 写「对方确认企业主体前不会生成合作关系」，和「会员已存在自动建立」需对齐。建议：会员只有一个组织时打开链接直接建立；有多个组织时先选组织。
